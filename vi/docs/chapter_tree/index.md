# Cây

![Cây](../assets/covers/chapter_tree.jpg)

!!! abstract

    Chương này giới thiệu cây nhị phân, các thuật ngữ và thao tác cơ bản, bốn cách duyệt, biểu diễn cây bằng mảng, cây tìm kiếm nhị phân và cây AVL. Trọng tâm là hiểu cấu trúc phân cấp, mối liên hệ giữa hình dạng cây với hiệu suất, và cách duy trì thứ tự hoặc cân bằng để các thao tác vẫn hiệu quả.
