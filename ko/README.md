# Hello Algo 한국어판

이 디렉터리는 [Hello Algo](https://github.com/krahets/hello-algo)의 비공식 한국어 번역 초안입니다. 영어 원문 커밋 `a3166c201853739213d5a3a31b1e4a237aaf1076`을 기준으로 하며, 완성된 한국어 Atlas와 공식 목차에 대응하는 119/119개 문서 경로를 제공합니다. 각 읽기 페이지에는 정확한 VI/EN 대응 문서, 제목 검색, 글 안의 목차, 원문의 13개 언어 코드 탭이 있습니다. 원문보다 간략한 문서는 생성된 parity 보고서로 추적하며, 구조·기술·한국어 검토 기준을 통과하기 전까지 모두 초안으로 유지합니다.
