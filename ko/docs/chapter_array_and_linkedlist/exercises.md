# 연습문제

## 개념 복습

### 배열과 연결 리스트는 원소를 어떻게 찾을까?

배열과 단일 연결 리스트가 모두 `[A, B, C, D, E]`를 저장합니다. 네 번째 원소 `D`에 접근하세요.

1. 배열은 어떤 인덱스를 바로 사용할 수 있습니까?
2. 머리 노드 `A`에서 어떤 노드를 차례로 방문합니까?
3. 요청 위치가 뒤로 갈수록 단계 수는 어떻게 달라집니까?

??? success "정답"

    1. 0부터 시작하는 인덱스에서는 `arr[3]`을 $O(1)$에 접근합니다.
    2. 연결 리스트는 `A → B → C → D`로 세 번 `next`를 따라갑니다.
    3. 배열의 위치 접근은 계속 $O(1)$이지만 연결 리스트는 최악의 경우 $O(n)$입니다.

### 배열과 연결 리스트는 원소를 어떻게 삽입할까?

배열 `[A, B, C, D, _]`에는 한 칸이 남아 있습니다. 연결 리스트는 `A → B → C → D`이고 `B`의 참조를 이미 알고 있습니다. `B` 뒤에 `X`를 넣으세요.

??? success "정답"

    배열은 `D`, `C`를 오른쪽으로 옮긴 뒤 인덱스 2에 `X`를 넣어 `[A, B, X, C, D]`를 만듭니다. 연결 리스트는 먼저 `X.next = B.next`, 다음에 `B.next = X`로 바꿔 `A → B → X → C → D`를 만듭니다. `B`를 이미 알면 링크 변경은 $O(1)$이지만, 머리에서 `B`를 찾아야 한다면 $O(n)$이 걸릴 수 있습니다.

### 리스트의 용량은 어떻게 늘어날까?

배열 기반 리스트 `[A, B, C]`의 `size = 3`, `capacity = 4`이고 가득 차면 용량을 두 배로 늘립니다. `D`와 `E`를 차례로 추가하면 어떻게 됩니까?

??? success "정답"

    `D`는 마지막 빈칸에 들어가므로 `size = 4`, `capacity = 4`입니다. `E`를 추가할 때 용량 8의 새 배열을 만들고 기존 네 원소를 복사하므로 결과는 `size = 5`, `capacity = 8`입니다. 기존 배열이 커지는 것이 아니라 리스트가 더 큰 배열로 교체합니다.

## 프로그래밍 연습

### 배열로 저장한 큰 정수에 1 더하기

`digits`는 십진수 각 자릿수를 왼쪽부터 저장합니다. 세로셈을 흉내 내어 1을 더한 결과 배열을 반환하세요.

??? tip "힌트"

    마지막 자릿수부터 시작합니다. 9보다 작으면 1을 더하고 끝내고, 9이면 0으로 바꾼 뒤 계속합니다. 모든 자릿수가 9라면 맨 앞에 1을 추가합니다.

[LeetCode](https://leetcode.com/problems/plus-one/)

### 단일 연결 리스트 뒤집기

머리 노드 `head`가 주어질 때 새 노드를 만들지 않고 반복문으로 모든 연결을 뒤집고 새 머리를 반환하세요.

??? tip "힌트"

    `prev`, `cur`, `nxt`를 사용합니다. `cur.next`를 바꾸기 전에 `nxt = cur.next`를 저장한 뒤 두 포인터를 전진시킵니다.

[LeetCode](https://leetcode.com/problems/reverse-linked-list/)
