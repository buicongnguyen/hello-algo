# 기본 데이터형

컴퓨터의 데이터는 텍스트, 이미지, 동영상, 오디오, 3D 모델처럼 여러 모습으로 나타납니다. 조직 방식은 서로 다르지만, 가장 작은 구성 요소를 따라 내려가면 모두 여러 기본 데이터형으로 이루어져 있습니다. 알고리즘은 이 값들을 읽고 비교하고 계산하면서 더 복잡한 정보를 처리합니다.

**기본 데이터형은 CPU가 직접 연산할 수 있는 데이터형입니다.** 주요 범주는 다음과 같습니다.

- 정수형 `byte`, `short`, `int`, `long`
- 소수를 표현하는 부동소수점형 `float`, `double`
- 여러 언어의 글자, 문장 부호, 기호와 이모지를 나타내는 문자형 `char`
- “예”와 “아니요”, 참과 거짓 두 상태를 나타내는 불리언형 `bool`

기본 데이터형은 이진수로 저장됩니다. 이진수 한 자리는 1비트이며, 대부분의 현대 운영체제에서 $1$바이트는 $8$비트입니다.

CPU의 산술·논리 장치는 이러한 고정된 비트 묶음을 직접 읽어 연산합니다. 데이터형은 같은 비트 배열을 정수, 실수, 문자 또는 논리값 중 무엇으로 해석할지를 정합니다. 따라서 메모리에 저장된 비트만으로는 의미가 완성되지 않으며, 프로그램이 적용하는 데이터형과 표현 규칙이 함께 필요합니다.

값의 범위는 데이터형에 할당된 비트 수와 표현 방식에 따라 달라집니다. 같은 비트 수라도 정수와 부동소수점수는 비트를 해석하는 규칙이 다르므로 범위와 정밀도가 서로 다릅니다. 우선 Java의 정수형을 예로 들면 다음과 같습니다.

- `byte`는 $1$바이트, 즉 $8$비트를 사용하여 $2^8$개의 값을 표현합니다.
- `int`는 $4$바이트, 즉 $32$비트를 사용하여 $2^{32}$개의 값을 표현합니다.

다음 표는 Java 기본 데이터형이 차지하는 공간, 값의 범위, 기본값을 정리한 것입니다. 모두 외울 필요는 없으며, 전체 모습을 이해하고 필요할 때 찾아보면 충분합니다.

| 범주 | 데이터형 | 크기 | 최솟값 | 최댓값 | 기본값 |
| --- | --- | --- | --- | --- | --- |
| 정수 | `byte` | 1바이트 | $-2^7$ ($-128$) | $2^7 - 1$ ($127$) | $0$ |
| 정수 | `short` | 2바이트 | $-2^{15}$ | $2^{15} - 1$ | $0$ |
| 정수 | `int` | 4바이트 | $-2^{31}$ | $2^{31} - 1$ | $0$ |
| 정수 | `long` | 8바이트 | $-2^{63}$ | $2^{63} - 1$ | $0$ |
| 실수 | `float` | 4바이트 | $1.175 \times 10^{-38}$ | $3.403 \times 10^{38}$ | $0.0\text{f}$ |
| 실수 | `double` | 8바이트 | $2.225 \times 10^{-308}$ | $1.798 \times 10^{308}$ | $0.0$ |
| 문자 | `char` | 2바이트 | $0$ | $2^{16} - 1$ | $0$ |
| 불리언 | `bool` | 1바이트 | $\text{false}$ | $\text{true}$ | $\text{false}$ |

이 표는 Java의 기본 데이터형을 설명합니다. 언어마다 정의가 다르므로 크기, 값의 범위, 기본값도 달라질 수 있습니다.

정수형은 비트 수가 늘어날수록 표현 가능한 값의 개수가 지수적으로 늘어납니다. 부동소수점형은 일부 비트를 지수에 사용하여 매우 큰 값과 매우 작은 값을 다루지만 모든 실수를 정확히 표현하지는 못합니다. 문자형의 범위는 문자 집합과 인코딩에 연결되고, 불리언형은 두 상태만 필요하더라도 CPU가 주소를 지정하는 단위에 맞추어 저장됩니다. 표의 숫자를 외우기보다 각 범위가 왜 달라지는지를 이해하는 편이 더 중요합니다.

- Python의 `int`는 메모리가 허용하는 범위에서 임의 정밀도를 지원합니다. `float`는 보통 64비트 배정밀도 실수입니다. 별도의 `char`형은 없으며 문자 하나는 길이가 1인 `str`입니다.
- C와 C++은 모든 기본 데이터형의 크기를 하나로 고정하지 않습니다. 크기는 구현과 플랫폼에 따라 달라집니다. 위 범위는 Linux와 macOS 같은 64비트 Unix 운영체제에서 흔한 LP64 [데이터 모델](https://en.cppreference.com/w/cpp/language/types#Properties)을 기준으로 이해할 수 있습니다.
- C와 C++의 `char`는 1바이트입니다. 다른 언어에서 문자 하나가 차지하는 공간은 뒤에서 살펴볼 문자 인코딩 방식과 연결됩니다.
- 이론적으로 불리언 값 $0$ 또는 $1$을 표현하는 데에는 1비트면 충분합니다. 하지만 현대 CPU가 직접 주소를 지정하는 가장 작은 메모리 단위가 보통 1바이트이므로 실제로는 1바이트 이상을 차지하는 경우가 많습니다.

기본 데이터형과 자료구조는 어떤 관계일까요? 자료구조는 컴퓨터에서 데이터를 조직하고 저장하는 방식입니다. 여기서 강조하는 것은 데이터 자체가 아니라 데이터 사이의 **구조와 관계**입니다. 반대로 기본 데이터형은 각 원소가 어떤 종류의 값을 담는지를 설명합니다.

예를 들어 “한 줄로 놓인 수”를 표현한다면 자연스럽게 배열을 떠올릴 수 있습니다. 배열의 선형 구조가 수들의 인접 관계와 순서를 나타내기 때문입니다. 그 배열에 들어가는 값이 정수 `int`, 실수 `float`, 문자 `char` 중 무엇인지는 배열이라는 조직 방식과 별개의 문제입니다.

즉, **기본 데이터형은 데이터의 ‘내용 유형’을 제공하고 자료구조는 데이터의 ‘조직 방법’을 제공합니다.** 같은 배열 구조로 정수, 실수, 문자, 불리언을 각각 저장할 수 있습니다. Python 리스트는 서로 다른 종류의 객체에 대한 참조도 한 리스트에 함께 저장할 수 있지만, 리스트가 제공하는 순서 관계는 그대로 유지됩니다.

반대 방향으로도 같은 구분이 적용됩니다. 동일한 정수 값들을 배열, 연결 리스트, 스택, 큐에 넣을 수 있으며, 내용 유형은 정수로 같아도 원소 사이의 관계와 허용되는 연산은 달라집니다. 알고리즘을 설계할 때에는 먼저 저장할 값의 유형을 정한 뒤, 필요한 접근·삽입·삭제 패턴에 맞는 자료구조를 선택해야 합니다.

```python
# 여러 기본 데이터형을 나타내는 리스트
numbers: list[int] = [0] * 5
decimals: list[float] = [0.0] * 5
characters: list[str] = ["0"] * 5
bools: list[bool] = [False] * 5

# Python 리스트는 서로 다른 종류의 객체를 함께 담을 수 있습니다
data = [0, 0.0, "a", False, object()]
```
