# 연습문제

## 개념 복습

### 일상 상황의 데이터 관계

역과 연결 구간으로 이루어진 지하철 노선, 상하 관계가 있는 조직도, 표를 사려고 선 사람들을 각각 어떤 구조로 모델링할 수 있는지 설명하세요.

??? success "정답"

    지하철은 한 역이 여러 역과 연결될 수 있으므로 그래프, 조직도는 계층 관계를 가지므로 트리, 대기 줄은 먼저 온 사람이 먼저 처리되므로 큐가 적합합니다.

### 논리적 순서를 메모리에 저장하기

같은 순서의 원소를 연속된 배열 또는 흩어진 연결 노드로 저장할 때 논리 구조와 물리 구조를 비교하세요.

??? success "정답"

    둘 다 선형 순서를 표현합니다. 배열은 연속 메모리와 인덱스를 사용하고, 연결 리스트는 흩어진 노드 사이의 참조로 순서를 유지합니다. 논리 구조는 같지만 물리 구조는 다릅니다.

### 과제 기록의 데이터형과 구조

학생 번호, 이름, 과목별 점수, 제출한 과목 목록을 저장할 때 기본 데이터형과 복합 자료구조를 구분하세요.

??? success "정답"

    번호와 점수는 수, 이름은 문자열, 제출 여부는 불리언으로 표현할 수 있습니다. 레코드나 클래스가 한 학생의 필드를 묶고, 배열이나 리스트가 점수와 과목을 저장하며, 해시 테이블은 학생 번호를 기록에 대응시킬 수 있습니다.

## 프로그래밍 연습

### 이진 표현에서 1의 개수 세기

음이 아닌 정수의 이진 표현에 포함된 `1`의 개수를 반환하세요.

??? tip "힌트"

    최하위 비트를 확인한 뒤 오른쪽으로 이동할 수 있습니다. `n &= n - 1`은 반복할 때마다 가장 낮은 `1` 비트를 제거합니다.
