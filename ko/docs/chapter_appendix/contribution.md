# 함께 기여하기

한정된 역량으로 책을 만들다 보니 빠진 내용과 오류를 완전히 피하기는 어렵습니다. 너그럽게 이해해 주시고, 바로잡는 일에 도움을 주시면 감사하겠습니다. 오탈자, 깨진 링크, 누락된 내용, 모호한 표현, 이해하기 어려운 설명, 구조상의 문제를 발견했다면 더 높은 품질의 학습 자료를 독자에게 제공할 수 있도록 함께 수정해 주세요.

작은 오탈자 하나를 바로잡는 일도 다음 독자의 혼란을 줄이며, 설명을 더 분명하게 고치는 일은 많은 학습자가 같은 개념을 다시 이해하는 데 도움을 줍니다.

모든 [기여자](https://github.com/krahets/hello-algo/graphs/contributors)의 GitHub ID는 오픈 소스 공동체를 위해 아낌없이 기여한 노력을 기리는 뜻에서 책 저장소 홈페이지, 웹 버전, PDF 버전에 표시됩니다.

!!! success "오픈 소스의 매력"

    종이책은 한 번 인쇄한 뒤 다음 인쇄까지의 간격이 긴 경우가 많아 내용을 갱신하기가 매우 불편합니다.

    이 오픈 소스 책에서는 내용 갱신에 걸리는 시간이 며칠, 때로는 몇 시간으로 단축됩니다.

### 작은 내용 수정

아래 그림처럼 각 페이지 오른쪽 위에는 “편집 아이콘”이 있습니다. 다음 절차에 따라 텍스트나 코드를 수정할 수 있습니다.

범위가 작은 변경은 검토하기 쉽고 빠르게 반영할 수 있으므로, 한 번의 제안에는 서로 관련된 수정만 담는 편이 좋습니다.

1. “편집 아이콘”을 클릭합니다. “Fork this repository”라는 안내가 나타나면 작업을 승인합니다.
2. Markdown 원본 파일의 내용을 수정하고 정확성을 확인하며, 가능한 한 기존 서식을 일관되게 유지합니다.
3. 페이지 아래쪽에 변경 설명을 입력한 뒤 “Propose file change” 버튼을 클릭합니다. 새 페이지가 열리면 “Create pull request” 버튼을 눌러 풀 리퀘스트를 제출합니다.

![페이지 편집 버튼](contribution.assets/edit_markdown.png)

이미지는 직접 수정할 수 없습니다. 새 [Issue](https://github.com/krahets/hello-algo/issues)를 만들거나 댓글을 남겨 문제를 설명해 주세요. 이미지를 신속히 다시 그리고 교체하겠습니다.

### 콘텐츠 작성

코드를 다른 프로그래밍 언어로 번역하거나 글의 내용을 확장하는 등 이 오픈 소스 프로젝트에 기여하고 싶다면 다음 Pull Request 절차를 따라야 합니다.

1. GitHub에 로그인하고 책의 [코드 저장소](https://github.com/krahets/hello-algo)를 개인 계정으로 Fork합니다.
2. Fork한 저장소 페이지로 이동한 뒤 `git clone` 명령으로 저장소를 로컬 컴퓨터에 복제합니다.
3. 로컬에서 콘텐츠를 작성하고 코드의 정확성을 확인할 수 있도록 충분히 테스트합니다.
4. 로컬 변경 사항을 커밋하고 원격 저장소로 푸시합니다.
5. 저장소 웹페이지를 새로 고친 뒤 “Create pull request” 버튼을 클릭해 풀 리퀘스트를 제출합니다.

### Docker 배포

`hello-algo`의 루트 디렉터리에서 다음 Docker 명령을 실행하면 `http://localhost:8000`으로 프로젝트에 접속할 수 있습니다.

```shell
docker-compose up -d
```

배포를 제거하려면 다음 명령을 사용합니다.

```shell
docker-compose down
```
