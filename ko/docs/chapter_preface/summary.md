# 요약

### 핵심 복습

- 이 책의 주요 독자는 알고리즘 입문자입니다. 이미 어느 정도 배경지식이 있다면 알고리즘 지식을 체계적으로 복습하는 데 활용할 수 있고, 책의 소스 코드는 “문제 풀이 도구 상자”로도 사용할 수 있습니다.
- 책의 내용은 크게 복잡도 분석, 자료구조, 알고리즘의 세 부분으로 구성되며 이 분야의 주요 주제를 대부분 다룹니다.
- 알고리즘을 처음 배우는 사람에게 초기 단계의 입문서 읽기는 매우 중요합니다. 체계적인 안내를 따르면 불필요한 시행착오를 줄일 수 있습니다.
- 움직이는 그림은 대개 핵심 개념과 어려운 주제를 소개하는 데 사용됩니다. 책을 읽을 때 이러한 그림과 설명에 더 주의를 기울이세요.
- 실습은 프로그래밍을 배우는 가장 좋은 방법입니다. 소스 코드를 실행하고 직접 입력해 보기를 강하게 권합니다.
- 원본 웹 버전은 각 장에 댓글 영역을 제공합니다. 언제든 질문과 통찰을 나누며 공동체 학습에 참여할 수 있습니다.
- 먼저 그림으로 상태 변화를 파악하고, 코드의 각 줄이 그 변화에 어떻게 대응하는지 확인한 다음, 입력과 경계 조건을 바꾸어 다시 실행하면 이해를 더 단단하게 만들 수 있습니다.
- 이 책은 알고리즘 입문의 첫 단계를 중심으로 하며, 이후 문제 풀이 연습과 지식 체계 구축으로 나아갈 수 있는 공통 기반을 마련합니다.
