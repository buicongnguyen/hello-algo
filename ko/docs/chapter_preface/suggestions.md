## 표기 방식과 문체 규칙

- 제목 뒤에 `*`가 표시된 절은 선택 사항이며 난도가 조금 더 높습니다. 시간이 부족하다면 첫 번째 학습에서는 건너뛰어도 됩니다.
- 기술 용어는 인쇄본과 PDF에서는 굵게, 웹에서는 밑줄로 표시합니다. 예를 들어 <u>배열</u>처럼 나타납니다. 기술 문서를 읽는 데 도움이 되므로 기억해 둘 가치가 있습니다.
- 핵심 내용과 요약 문장은 **굵게 표시**하며, 특별히 주의해서 읽어야 합니다.
- 특정한 뜻으로 쓰인 단어나 구는 모호함을 피하기 위해 “따옴표”로 표시합니다.
- 프로그래밍 언어마다 용어가 다를 때는 Python의 관례를 따릅니다. 예를 들어 “널”을 나타낼 때 `None`을 사용합니다.
- 책의 레이아웃을 간결하게 유지하기 위해 일반적인 언어별 주석 양식을 일부 완화했습니다. 주석은 주로 제목 주석, 내용 주석, 여러 줄 주석의 세 종류로 나눕니다.

이 규칙은 여러 언어의 코드를 한 문서에서 비교할 때 표현을 일관되게 유지하기 위한 것입니다. 제목 뒤의 별표, 밑줄 친 용어, 굵은 결론과 따옴표의 의미를 미리 알면 본문에서 무엇을 먼저 읽고 무엇을 나중에 깊이 살펴볼지 쉽게 판단할 수 있습니다. 아래 언어 탭에서는 같은 세 가지 주석 역할이 언어별 문법으로 어떻게 표현되는지 비교할 수 있습니다.

## 코드 실습으로 이해 깊이기

이 책의 예제 코드는 [GitHub 저장소](https://github.com/krahets/hello-algo)에 공개되어 있습니다. 아래 그림처럼 **소스 코드에는 테스트 케이스가 포함되어 있고 한 번의 동작으로 실행할 수 있습니다**.

시간이 허락한다면 **코드를 직접 입력해 보기를 권합니다**. 학습 시간이 부족하더라도 모든 코드를 읽고 실행해 보세요.

코드를 읽기만 하는 것보다 직접 작성할 때 더 많은 것을 배울 수 있습니다. **진짜 학습은 손으로 실습하는 과정에서 일어납니다**.

![코드 실행 예](../index.assets/running_code.gif)

직접 입력하면 변수 이름, 경계 조건, 호출 순서처럼 눈으로 읽을 때 지나치기 쉬운 세부 사항을 확인하게 됩니다. 실행하기 전에 결과를 먼저 예상하고 실제 출력과 비교하면, 단순히 정답을 복사하는 것보다 알고리즘의 상태 변화를 훨씬 분명하게 이해할 수 있습니다.

코드를 실행하기 위한 준비 과정은 크게 세 단계입니다.

**1단계: 로컬 프로그래밍 환경 설치**. 부록의 [설치 안내](https://www.hello-algo.com/chapter_appendix/installation/)를 따르세요. 이미 환경을 설치했다면 이 단계는 건너뛸 수 있습니다.

**2단계: 코드 저장소 복제 또는 다운로드**. [GitHub 저장소](https://github.com/krahets/hello-algo)를 방문하세요. [Git](https://git-scm.com/downloads)을 설치했다면 다음 명령으로 저장소를 복제할 수 있습니다.

```shell
git clone https://github.com/krahets/hello-algo.git
```

또는 아래 그림의 “Download ZIP” 버튼을 눌러 저장소를 ZIP 파일로 직접 다운로드한 뒤 로컬에서 압축을 풀 수 있습니다.

![저장소 복제와 코드 다운로드](suggestions.assets/download_code.png)

**3단계: 소스 코드 실행**. 아래 그림처럼 코드 블록 위에 파일 이름이 표시된 경우 저장소의 `codes` 폴더에서 대응하는 소스 파일을 찾을 수 있습니다. 소스 파일은 바로 실행할 수 있으므로 불필요한 디버깅 시간을 줄이고 학습 내용에 집중할 수 있습니다.

![문서의 코드 블록과 대응하는 소스 파일](suggestions.assets/code_md_to_repo.png)

로컬 실행뿐 아니라 **웹 버전에서는 Python 코드를 시각적으로 실행할 수도 있습니다**. 이 기능은 [Python Tutor](https://pythontutor.com/)를 기반으로 합니다. 아래 그림처럼 코드 블록 아래의 “Visual Run”을 누르면 실행 과정을 펼쳐 볼 수 있고, “Full Screen View”를 누르면 더 넓은 화면에서 확인할 수 있습니다.

![Python 코드의 시각적 실행](suggestions.assets/pythontutor_example.png)

시각적 실행에서는 한 단계씩 진행하면서 현재 줄, 변수 값, 호출 스택과 자료구조의 변화를 함께 관찰하세요. 로컬 실행은 다양한 입력을 빠르게 시험하는 데 좋고, 시각적 실행은 특정 단계에서 값이 왜 그렇게 바뀌는지 추적하는 데 유용하므로 두 방식을 함께 쓰는 것이 좋습니다.

## 알고리즘 학습 로드맵

자료구조와 알고리즘을 배우는 과정은 전체적으로 세 단계로 나눌 수 있습니다.

1. **1단계: 알고리즘 입문**. 여러 자료구조의 특징과 사용법에 익숙해지고, 다양한 알고리즘의 원리, 절차, 쓰임새와 효율성을 학습합니다.
2. **2단계: 알고리즘 문제 연습**. 널리 알려진 문제부터 시작해 먼저 100개 이상 풀어 보면서 대표적인 문제 유형에 익숙해지기를 권합니다. 처음에는 배운 지식을 잊는 일이 어려움처럼 느껴지지만 이는 자연스러운 과정입니다. 에빙하우스 망각 곡선에 따라 복습하고 3~5회 반복하면 대체로 기억에 단단히 자리 잡습니다. 추천 문제 목록과 연습 계획은 이 [GitHub 저장소](https://github.com/krahets/LeetCode-Book)를 참고하세요.
3. **3단계: 지식 체계 구축**. 알고리즘 칼럼, 문제 해결 프레임워크, 교재를 읽으며 지식 체계를 계속 확장합니다. 문제를 풀 때는 주제별 분류, 한 문제의 여러 풀이, 한 풀이를 여러 문제에 적용하는 방법 등 심화 전략을 시도할 수 있습니다. 관련 아이디어는 여러 기술 공동체에서도 찾을 수 있습니다.

아래 그림처럼 이 책의 내용은 주로 “1단계”를 다룹니다. 이를 토대로 2단계와 3단계의 학습을 더 효율적으로 진행하도록 돕는 것이 목표입니다.

![알고리즘 학습 로드맵](suggestions.assets/learning_route.png)

따라서 처음 읽을 때는 모든 내용을 암기하려 하기보다 각 자료구조의 특징과 연산, 각 알고리즘의 절차와 효율성을 설명할 수 있는 수준을 목표로 삼으세요. 이후 문제 연습에서 잊은 개념이 나오면 해당 절과 실행 가능한 예제로 돌아와 반복하면 지식 체계가 점차 연결됩니다.
