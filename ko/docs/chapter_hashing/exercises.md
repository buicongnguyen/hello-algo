# 연습문제

## 개념 복습

### 해시 충돌 뒤 검색하기

크기 7인 해시 테이블이 `hash(key) = key mod 7`을 사용합니다. `3`, `10`, `17`은 모두 인덱스 3에 대응합니다. 체이닝과 개방 주소법으로 `17`을 찾는 과정을 설명하세요.

??? success "정답"

    체이닝은 인덱스 3의 목록에서 `17`을 찾습니다. 개방 주소법은 삽입 때와 같은 탐사 순서를 따라 `17` 또는 한 번도 사용하지 않은 빈칸을 만날 때까지 진행합니다.

### 해시 테이블 확장 뒤 원소는 어디로 갈까?

테이블 크기가 7에서 13으로 바뀔 때 기존 인덱스에 그대로 복사하면 안 되는 이유는 무엇입니까?

??? success "정답"

    인덱스는 `key mod capacity`처럼 용량에 의존할 수 있습니다. 용량이 바뀌면 해시 위치도 바뀌므로 모든 키의 위치를 다시 계산해야 합니다. 이 재해싱은 한 번의 확장에 $O(n)$이 걸립니다.

### 6을 삭제한 뒤에도 11을 찾을 수 있을까?

선형 탐사를 쓰는 테이블에 충돌한 `1`, `6`, `11`이 연속으로 있습니다. `6`을 한 번도 사용하지 않은 빈칸처럼 지우면 어떤 문제가 생깁니까?

??? success "정답"

    검색이 빈칸에서 멈추어 `11`이 없다고 잘못 판단할 수 있습니다. 삭제 표시를 두거나 탐사 군집을 다시 배치해야 합니다.
