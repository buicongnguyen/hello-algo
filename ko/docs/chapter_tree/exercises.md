# 연습문제

## 개념 복습

### 완전·정·포화 이진 트리

세 개념의 차이와 포함 관계를 설명하세요.

??? success "정답"

    포화 이진 트리는 모든 레벨이 가득 찹니다. 완전 이진 트리는 마지막 레벨만 덜 찰 수 있고 그 노드가 왼쪽부터 연속되어야 합니다. 정 이진 트리는 모든 노드의 자식 수가 0 또는 2입니다. 모든 포화 이진 트리는 완전 이진 트리이면서 정 이진 트리지만 역은 항상 성립하지 않습니다.

### 같은 트리의 세 순회 순서

루트가 `A`, 왼쪽 서브트리가 두 자식 `D`, `E`를 가진 `B`, 오른쪽 자식이 `C`인 트리의 전위·중위·후위 순서를 쓰세요.

??? success "정답"

    전위는 `A, B, D, E, C`, 중위는 `D, B, E, A, C`, 후위는 `D, E, B, C, A`입니다. 루트를 두 서브트리보다 언제 방문하는지가 다릅니다.

### 두 이진 탐색 트리 비교

같은 키도 여러 모양의 이진 탐색 트리를 만들 수 있습니다. 균형 트리와 연결 리스트처럼 퇴화한 트리를 비교하세요.

??? success "정답"

    둘 다 작은 키는 왼쪽, 큰 키는 오른쪽에 둡니다. 균형 트리의 높이는 $O(\log n)$이지만 퇴화 트리는 $O(n)$이어서 검색도 선형으로 나빠질 수 있습니다.

## 프로그래밍 연습

### 이진 트리의 최대 깊이

루트에서 리프까지 가장 긴 경로에 포함된 노드 수를 반환하세요.

??? tip "힌트"

    빈 트리는 0입니다. 각 노드는 `1 + max(depth(left), depth(right))`를 반환합니다.

[LeetCode](https://leetcode.com/problems/maximum-depth-of-binary-tree/)

### 이진 트리를 레벨별로 순회하기

각 레벨의 노드 값을 왼쪽에서 오른쪽 순서로 반환하세요.

??? tip "힌트"

    큐를 사용합니다. 각 레벨을 시작할 때 큐 크기를 기록하면 현재 레벨의 노드 수를 알 수 있습니다.

[LeetCode](https://leetcode.com/problems/binary-tree-level-order-traversal/)

### 이진 탐색 트리의 k번째 작은 원소

이진 탐색 트리와 `k`가 주어질 때 `k`번째로 작은 키를 반환하세요.

??? tip "힌트"

    중위 순회는 키를 오름차순으로 방문합니다. `k`번째 원소를 방문하면 즉시 멈출 수 있습니다.

[LeetCode](https://leetcode.com/problems/kth-smallest-element-in-a-bst/)
