# 연습문제

## 개념 복습

### 완전·정·포화 이진 트리

다음 두 배열은 레벨 순서로 이진 트리를 표현하며, `None`은 빈 위치를 뜻합니다.

- 트리 A: `[1, 2, 3, 4, 5, 6]`
- 트리 B: `[1, 2, 3, None, None, 6, 7]`

배열 인덱스가 나타내는 빈자리까지 트리 구조의 일부로 해석해야 합니다. 값만 앞쪽으로 당겨 읽으면 다른 부모–자식 관계가 만들어집니다.

<!-- numbered-subquestions -->

1. 어느 트리가 완전 이진 트리인가요?
2. 어느 트리가 정 이진 트리, 즉 리프가 아닌 모든 노드가 정확히 두 자식을 가지는 트리인가요?
3. 포화 이진 트리가 있나요? 각 트리에 대해 이유를 설명하세요.

??? success "정답"

    1. 트리 A가 완전 이진 트리입니다. 마지막 레벨만 덜 채워졌고 그 레벨의 노드가 왼쪽부터 끊김 없이 놓였습니다. 트리 B는 왼쪽에 빈 위치가 있는데 오른쪽에 노드가 남아 있으므로 완전하지 않습니다.

    2. 트리 B가 정 이진 트리입니다. 노드 1과 3은 각각 자식 둘을 가지고 나머지는 모두 리프입니다. 트리 A는 노드 3에 자식 6 하나만 있으므로 정 이진 트리가 아닙니다.

    3. 둘 다 포화 이진 트리가 아닙니다. 두 트리 모두 마지막 레벨 전체가 채워지지 않았습니다. 포화 조건은 모든 내부 노드가 자식 둘을 가진다는 것뿐 아니라 모든 레벨이 완전히 채워져야 한다는 더 강한 조건입니다.

### 같은 트리의 세 가지 순회

배열 `[1, 2, 3, 4, 5, 6, 7]`을 완전 이진 트리의 레벨 순서로 저장합니다.

<!-- numbered-subquestions -->

1. 트리를 그리세요.
2. 전위, 중위, 후위 순회 결과를 각각 쓰세요.
3. 중위 순회 결과에서 루트 1의 왼쪽과 오른쪽 구간은 트리의 어느 부분에 대응하나요?

??? success "정답"

    1. 트리 모양은 다음과 같습니다.

        ```text
              1
            /   \
           2     3
          / \   / \
         4   5 6   7
        ```

    2. 전위 순서는 `1, 2, 4, 5, 3, 6, 7`, 중위 순서는 `4, 2, 5, 1, 6, 3, 7`, 후위 순서는 `4, 5, 2, 6, 7, 3, 1`입니다.

    3. `4, 2, 5`는 왼쪽 서브트리의 중위 순회 결과이고, `6, 3, 7`은 오른쪽 서브트리의 중위 순회 결과입니다. 중위 순회는 왼쪽 서브트리를 모두 방문한 뒤 루트 1을 방문하고 마지막으로 오른쪽 서브트리를 방문합니다.

### 두 이진 탐색 트리 비교

다음 두 수열을 각각 빈 BST에 순서대로 삽입합니다.

- 수열 A: `[4, 2, 6, 1, 3, 5, 7]`
- 수열 B: `[1, 2, 3, 4, 5, 6, 7]`

값 집합은 같지만 삽입 순서가 다르므로 트리 모양과 탐색 경로가 달라집니다.

<!-- numbered-subquestions -->

1. 각 트리에서 7을 찾을 때 방문하는 노드를 나열하세요.
2. 높이를 루트에서 가장 먼 리프까지의 간선 수로 정의할 때 각 트리 높이는 얼마인가요?
3. 7을 찾는 효율이 같은가요? 트리 모양과 탐색 경로를 이용해 설명하세요.

??? success "정답"

    1. 트리 A의 경로는 `4 → 6 → 7`이고 트리 B의 경로는 `1 → 2 → 3 → 4 → 5 → 6 → 7`입니다.

    2. 트리 A는 모든 레벨이 채워져 높이가 2입니다. 트리 B는 오른쪽 자식만 이어지므로 높이가 6입니다.

    3. 같지 않습니다. 삽입 순서가 BST의 모양과 높이를 바꿉니다. 트리 A는 노드 3개만 방문하지만 트리 B는 7개를 모두 방문해야 합니다. 높이가 커질수록 최악의 탐색 경로도 길어집니다. 단순 BST는 순서 조건을 지켜도 자동으로 균형을 복구하지 않는다는 점을 보여 줍니다.

## 프로그래밍 연습

### 이진 트리의 최대 깊이

이진 트리의 루트 `root`가 주어집니다. 각 노드는 정수 하나와 왼쪽·오른쪽 자식 참조를 가집니다.

이 문제의 최대 깊이는 루트에서 가장 먼 리프까지 경로에 포함된 **노드 수**입니다. 최대 깊이를 반환하세요. 빈 트리의 깊이는 0이며 재귀를 사용해야 합니다. 본문의 간선 수 정의와 문제의 노드 수 정의가 다르다는 점에 주의하세요.

??? tip "힌트"

    1. 노드 수를 세므로 루트 하나뿐인 트리의 최대 깊이는 1입니다.
    2. 재귀 함수가 현재 노드를 루트로 하는 서브트리의 최대 깊이를 반환하게 하세요.
    3. 빈 노드는 0을 반환하고, 비어 있지 않은 노드는 `max(depth(left), depth(right)) + 1`을 반환합니다.
    4. 두 자식 결과를 모두 구한 뒤 더 큰 값에 현재 노드 하나를 더하면 됩니다.

### 이진 트리 레벨 순회

이진 트리의 `root`가 주어집니다. 큐를 사용해 위에서 아래로, 같은 레벨에서는 왼쪽에서 오른쪽으로 모든 노드를 방문하세요.

2차원 배열을 반환합니다. 첫 번째 내부 배열에는 루트 레벨의 값, 두 번째에는 다음 레벨의 값이 들어가며 이후도 같은 방식입니다. 빈 트리는 빈 배열을 반환합니다. 다음 레벨의 자식을 큐에 넣는 동안 현재 레벨의 경계를 잃지 않는 것이 핵심입니다.

??? tip "힌트"

    1. 레벨 순회는 먼저 들어온 노드를 먼저 처리하므로 큐를 사용하세요.
    2. 각 반복의 시작 시점에 큐에 있는 모든 노드는 같은 레벨에 속합니다.
    3. 큐 길이를 먼저 기록한 뒤 정확히 그 수만큼 노드를 꺼내고, 자식은 다음 반복을 위해 큐 뒤에 넣으세요.
    4. 노드를 꺼낼 때 그 값을 현재 레벨 배열에 추가하고, 레벨 처리가 끝나면 결과 배열에 넣으세요.

### BST에서 k번째로 작은 원소

서로 다른 값을 가진 노드 `n`개로 구성된 BST가 있습니다. 모든 값을 오름차순으로 놓았을 때 위치는 1부터 셉니다.

`root`와 `1 <= k <= n`을 만족하는 정수 `k`가 주어질 때 `k`번째 값을 반환하세요. 모든 값을 배열에 먼저 모으지 말고 중위 순회 도중 직접 찾으세요. 목표를 찾은 뒤 더 이상 필요 없는 재귀를 멈출 수 있는 상태 전달 방법도 생각해 보세요.

??? tip "힌트"

    1. BST의 중위 순회는 값을 작은 것부터 큰 것 순서로 방문합니다.
    2. 왼쪽 서브트리, 현재 노드, 오른쪽 서브트리 순으로 처리하고 현재 노드를 방문할 때 카운터를 증가시키세요.
    3. 카운터가 처음 `k`와 같아질 때 현재 노드 값이 정답이며 순회를 중단할 수 있습니다.
    4. 반복 버전에서는 스택으로 왼쪽 경로를 쌓고, 노드를 꺼낼 때마다 카운터를 증가시킬 수 있습니다.
