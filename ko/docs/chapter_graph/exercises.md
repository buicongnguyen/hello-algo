# 연습문제

## 개념 복습

### 같은 그래프를 두 가지 방식으로 표현하기

정점 `A, B, C, D`와 간선 `A-B, A-C, B-C, C-D`를 가진 무방향 그래프가 있습니다.

<!-- numbered-subquestions -->

1. 그래프의 인접 리스트를 작성하세요.
2. 0과 1만 사용하는 인접 행렬을 채우세요.
3. `A`와 `D`가 직접 연결되었는지 확인할 때 어느 표현은 저장 위치 하나만 보면 되나요?
4. 정점은 많지만 간선이 적은 그래프에서 어느 표현이 보통 공간을 덜 사용하나요?

??? success "정답"

    1. 인접 리스트는 다음과 같습니다.

        ```text
        A: B, C
        B: A, C
        C: A, B, D
        D: C
        ```

    2. 인접 행렬은 다음과 같습니다.

        | | A | B | C | D |
        | --- | --- | --- | --- | --- |
        | A | 0 | 1 | 1 | 0 |
        | B | 1 | 0 | 1 | 0 |
        | C | 1 | 1 | 0 | 1 |
        | D | 0 | 0 | 1 | 0 |

    3. 인접 행렬에서는 `A`행과 `D`열이 만나는 원소 하나만 확인하면 되므로 두 정점이 직접 연결되었는지 판단하기 좋습니다.

    4. 정점이 많지만 간선이 적으면 인접 리스트는 실제 간선만 기록하므로 보통 공간을 덜 사용합니다. 인접 행렬은 모든 정점 쌍에 저장 위치를 마련합니다.

### 너비 우선과 깊이 우선 순서

정점 `A, B, C, D, E`와 간선 `A-B, A-C, B-D, C-D, D-E`를 가진 무방향 그래프가 있습니다.

A에서 시작하고, 아직 방문하지 않은 인접 정점이 여러 개이면 항상 알파벳 순으로 선택합니다.

<!-- numbered-subquestions -->

1. BFS 방문 순서를 작성하세요.
2. 재귀 DFS 방문 순서를 작성하세요.
3. 두 순회 모두 방문한 정점을 기록해야 하는 이유는 무엇인가요?

??? success "정답"

    1. BFS 순서는 `A, B, C, D, E`입니다. 먼저 A에서 간선 하나 거리인 B와 C를 방문하고, 그다음 더 먼 D와 E를 방문합니다.

    2. DFS 순서는 `A, B, D, C, E`입니다. 방문하지 않은 인접 정점을 따라 먼저 `A → B → D → C` 경로로 깊이 이동합니다. C에서 새 정점이 없으면 D로 돌아가 E를 방문합니다.

    3. 그래프에는 `A-B-D-C-A` 같은 사이클이 있습니다. 방문 여부를 기록하지 않으면 알고리즘이 사이클을 계속 돌며 정상적으로 끝나지 않을 수 있습니다.

### 한 번의 BFS로 전체 그래프를 방문할 수 있나요?

정점 `A, B, C, D, E, F`와 간선 `A-B, B-C, D-E`만 가진 무방향 그래프가 있습니다.

<!-- numbered-subquestions -->

1. A에서 시작한 한 번의 BFS는 어떤 정점을 방문할 수 있나요?
2. 이 BFS가 모든 정점을 방문했나요? 그 이유를 설명하세요.
3. 모든 정점을 알파벳 순으로 검사하고 아직 방문하지 않은 정점마다 새 BFS를 시작한다고 합시다. 각 BFS의 시작 정점은 무엇이며 그래프는 몇 개의 연결 요소로 나뉘나요?

??? success "정답"

    1. A에서 시작하면 `A, B, C`만 방문할 수 있습니다.

    2. 아닙니다. `D, E`는 다른 연결 요소를 이루고 F는 고립 정점입니다. 어느 정점도 A로 가는 경로가 없으므로 A에서 도달할 수 없습니다.

    3. 세 번의 BFS는 `A, D, F`에서 시작하여 각각 `{A, B, C}`, `{D, E}`, `{F}`를 방문합니다. 따라서 그래프에는 연결 요소가 3개 있습니다.

## 프로그래밍 연습

### 무방향 그래프에서 경로 존재 여부 확인

$0$부터 $n-1$까지 번호가 붙은 $n$개의 정점을 가진 무방향 그래프가 주어집니다. 배열 `edges`의 각 원소 `[u, v]`는 정점 `u`와 `v` 사이의 무방향 간선을 나타냅니다.

시작 정점 `source`와 도착 정점 `destination`도 주어집니다. 먼저 `edges`로 인접 리스트를 만든 뒤 BFS 또는 DFS를 사용하여 `source`에서 `destination`으로 가는 경로가 있는지 확인하세요. 경로가 있으면 `true`, 없으면 `false`를 반환합니다. 그래프에는 사이클이 있을 수 있고 비연결일 수도 있습니다.

??? tip "힌트"

    1. 각 무방향 간선을 양방향으로 추가하세요.
    2. 그래프에는 사이클이 있을 수 있으므로 방문한 정점을 기록해야 합니다.
    3. `source`에서 시작하여 `destination`을 만나면 `true`를 반환하세요. 순회가 끝날 때까지 도착 정점을 만나지 못하면 `false`를 반환합니다.
