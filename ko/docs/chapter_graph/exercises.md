# 연습문제

## 개념 복습

### 같은 그래프를 두 방식으로 표현하기

무방향 그래프의 정점이 `A, B, C, D`, 간선이 `A-B`, `A-C`, `B-D`, `C-D`입니다. 인접 리스트와 인접 행렬을 작성하세요.

??? success "정답"

    인접 리스트는 `A:{B,C}`, `B:{A,D}`, `C:{A,D}`, `D:{B,C}`입니다. 인접 행렬은 `A,B,C,D` 순서의 행과 열을 두고 간선이 있으면 1입니다. 무방향 그래프이므로 주대각선을 기준으로 대칭입니다.

### 너비 우선과 깊이 우선 순회 순서

`A`에서 시작하고 인접 정점을 알파벳순으로 확인할 때 위 그래프의 BFS와 DFS 순서를 쓰세요.

??? success "정답"

    BFS는 `A, B, C, D`, 가능한 DFS는 `A, B, D, C`입니다. 인접 정점 확인 순서가 다르면 방문 순서도 달라질 수 있지만 방문하는 정점 집합은 같습니다.

### 한 번의 BFS로 전체 그래프를 방문할 수 있을까?

그래프에 여러 연결 요소가 있으면 한 정점에서 시작한 BFS가 모든 정점을 방문합니까?

??? success "정답"

    아닙니다. 시작 정점이 속한 연결 요소만 방문합니다. 전체를 순회하려면 모든 정점을 확인하며 아직 방문하지 않은 정점에서 새 BFS를 시작해야 합니다.

??? tip "힌트"

    인접 리스트를 만들고 `visited` 집합과 함께 BFS 또는 DFS를 사용합니다. 목적지를 만나면 즉시 끝낼 수 있습니다.
