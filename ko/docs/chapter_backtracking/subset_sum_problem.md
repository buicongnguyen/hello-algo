# 부분집합 합 문제

## 중복 원소가 없는 배열

!!! question

    양의 정수 배열 `nums`와 양의 목표 정수 `target`이 주어집니다. 원소의 합이 `target`인 모든 조합을 찾으세요. 배열에는 중복 원소가 없고 각 원소는 여러 번 선택할 수 있습니다. 서로 중복되지 않는 조합 목록을 반환하세요.

예를 들어 집합 $\{3, 4, 5\}$와 목표값 $9$의 해는 $\{3, 3, 3\}, \{4, 5\}$입니다. 두 가지를 주의해야 합니다.

- 입력 집합의 원소는 제한 없이 반복 선택할 수 있습니다.
- 부분집합은 순서를 구분하지 않으므로 $\{4, 5\}$와 $\{5, 4\}$는 같은 부분집합입니다.

### 순열 해법 참고

순열 문제처럼 부분집합 생성도 연속된 선택으로 볼 수 있습니다. 원소를 선택할 때마다 현재 합을 갱신하고, 합이 `target`과 같아지면 상태를 복사해 결과 목록에 넣습니다.

순열과 달리 **이 문제에서는 각 원소를 몇 번이든 선택할 수 있으므로** 사용 여부를 기록하는 불리언 배열 `selected`가 필요하지 않습니다. 순열 코드를 조금 바꾸면 다음의 초기 해법을 얻습니다.

```python
# 잠긴 원문의 13개 언어 순진한 부분집합 합 공식 코드가 이 위치에 삽입됩니다.
```

배열 $[3, 4, 5]$와 목표 $9$로 실행하면 $[3, 3, 3], [4, 5], [5, 4]$를 얻습니다. **합이 $9$인 모든 부분집합을 찾았지만 $[4, 5]$와 $[5, 4]$라는 중복 결과가 포함됩니다.**

탐색 트리는 선택 순서를 구분하지만 부분집합은 순서를 구분하지 않기 때문입니다. 4를 선택한 뒤 5를 선택하는 가지와 5 뒤에 4를 선택하는 가지는 다르지만 같은 값의 집합을 나타냅니다.

![순서 때문에 생기는 중복 가지](subset_sum_problem.assets/subset_sum_i_naive.png)

모든 결과를 찾은 뒤 결과 목록에서 중복을 제거할 수도 있지만 매우 비효율적입니다.

- 배열 원소가 많고 특히 `target`이 클수록 탐색이 많은 중복 부분집합을 만듭니다.
- 배열 형태의 두 부분집합을 비교하려면 보통 정렬하고 각 원소를 확인해야 하며, 결국 버릴 결과까지 생성하고 보관해야 합니다.

더 좋은 방법은 중복 가지가 탐색 트리에 생기지 않도록 하는 것입니다.

입력이 모두 양수라는 조건도 중요합니다. 선택할수록 합은 감소하지 않으므로 목표를 넘은 상태는 이후 어떤 양수를 더해도 다시 목표로 돌아올 수 없습니다. 이 단조성이 목표 초과 가지치기의 근거가 됩니다. 음수가 허용되면 큰 값을 선택한 뒤 음수로 합을 줄일 수 있으므로 같은 종료 규칙은 안전하지 않습니다.

### 중복 부분집합 가지치기

**탐색 중 가지치기로 중복을 제거합니다.** 아래 그림에서 같은 원소 집합을 서로 다른 순서로 선택할 때 중복이 생깁니다.

1. 첫 번째와 두 번째 라운드에서 각각 $3$과 $4$를 선택하면 두 원소를 포함하는 모든 부분집합 $[3, 4, \dots]$가 만들어집니다.
2. 이후 첫 라운드에서 $4$를 선택했다면 **두 번째 라운드에서 $3$을 건너뛰어야 합니다.** $[4, 3, \dots]$ 가지는 이미 단계 `1.`에서 만든 가지와 완전히 중복됩니다.

각 깊이에서 선택을 왼쪽부터 오른쪽으로 순회하므로 오른쪽 가지일수록 더 많은 선택이 제거됩니다.

1. 앞의 두 라운드에서 $3$과 $5$를 선택하여 $[3, 5, \dots]$ 가지를 만듭니다.
2. 앞의 두 라운드에서 $4$와 $5$를 선택하여 $[4, 5, \dots]$ 가지를 만듭니다.
3. 첫 라운드에서 $5$를 선택했다면 **두 번째 라운드에서 $3$과 $4$를 모두 건너뛰어야 합니다.** $[5, 3, \dots]$와 $[5, 4, \dots]$는 각각 단계 `1.`과 `2.`의 가지와 중복됩니다.

![서로 다른 선택 순서가 만드는 중복 부분집합](subset_sum_problem.assets/subset_sum_i_pruning.png)

일반적으로 입력 배열이 $[x_1, x_2, \dots, x_n]$이고 선택열이 $[x_{i_1}, x_{i_2}, \dots, x_{i_m}]$이라고 합시다. 선택열은 $i_1 \leq i_2 \leq \dots \leq i_m$을 만족해야 하며, **이 조건을 만족하지 않는 모든 열은 중복이므로 가지치기합니다.** 인덱스 비감소 조건이 각 다중집합에 하나의 표준 순서만 허용합니다.

정렬과 `start`를 함께 사용하면 이 표준 순서를 코드로 강제할 수 있습니다. 현재 선택보다 왼쪽에 있는 후보를 다음 깊이에서 다시 보지 않으므로 선택 인덱스가 뒤로 가지 않습니다. 어떤 유효한 다중집합도 정렬된 순서로 한 번은 표현할 수 있으므로 중복을 제거하면서 해를 누락하지 않습니다.

### 코드 구현

가지치기를 구현하기 위해 선택 순회를 시작할 위치 `start`를 사용합니다. **$x_i$를 선택한 뒤 다음 라운드는 인덱스 $i$에서 시작합니다.** 선택열이 항상 $i_1 \leq i_2 \leq \dots \leq i_m$을 만족하면서 같은 원소도 다시 선택할 수 있습니다.

코드에는 두 가지 최적화가 더 있습니다.

- 탐색 전에 `nums`를 정렬합니다. 순회 중 **합이 `target`을 넘으면 반복문을 즉시 끝냅니다.** 뒤의 원소는 더 크므로 합을 더 증가시킬 뿐입니다.
- 합 `total`을 따로 저장하지 않고 **선택한 원소를 `target`에서 뺍니다.** `target`이 $0$이면 현재 상태가 하나의 해입니다.

남은 목표값을 상태로 사용하면 시도할 때 후보를 빼고 되돌릴 때 다시 더하는 대칭이 분명해집니다. 구현에 따라 정수 값을 함수 인자로 전달하면 각 호출이 자신의 남은 값을 가지므로 명시적으로 복원할 필요가 없고, 경로 목록만 제자리에서 되돌리면 됩니다. 반면 공유 변수로 관리한다면 경로와 함께 반드시 원상 복구해야 합니다.

```python
# 잠긴 원문의 13개 언어 중복 없는 부분집합 합 공식 코드가 이 위치에 삽입됩니다.
```

아래 그림은 배열 $[3, 4, 5]$와 목표 $9$에 대한 전체 백트래킹 과정입니다. 각 가지는 목표 도달, 목표 초과, 선택 소진 중 하나로 끝나고, 끝날 때마다 마지막 원소를 되돌린 뒤 다음 가지를 시도합니다.

## 중복 원소가 있는 배열

!!! question

    양의 정수 배열 `nums`와 양의 목표 정수 `target`이 주어집니다. 합이 `target`인 모든 조합을 찾으세요. **배열은 중복 원소를 포함할 수 있고 각 입력 위치는 최대 한 번만 선택할 수 있습니다.** 중복 없는 조합 목록을 반환하세요.

앞 문제와 달리 **입력 배열에 같은 값이 있을 수 있어** 새로운 중복이 생깁니다. 예를 들어 배열 $[4, \hat{4}, 5]$와 목표 $9$에서 이전 코드는 $[4, 5], [\hat{4}, 5]$를 반환합니다. 값의 열은 같은 두 부분집합입니다.

두 복사본은 입력 위치로는 구별되지만 문제의 결과는 위치가 아니라 값의 조합으로 정의됩니다. 따라서 같은 깊이에서 어느 복사본을 첫 원소로 선택하든 아래에 생기는 값의 조합은 동일합니다. 이 동등한 형제 가지 중 하나만 유지해야 합니다.

**같은 값의 원소를 한 선택 라운드에서 여러 번 고르기 때문에 중복이 발생합니다.** 아래 그림에서 첫 라운드는 값이 $4$인 두 선택을 포함하고, 이들이 두 개의 동일한 가지와 결과를 만듭니다. 두 번째 라운드의 두 $4$도 같은 문제를 일으킵니다.

![같은 원소가 만드는 중복 부분집합](subset_sum_problem.assets/subset_sum_ii_repeat.png)

### 같은 값 가지치기

이 문제를 해결하려면 **한 선택 라운드에서 같은 값은 한 번만 선택해야 합니다.** 배열을 정렬했으므로 같은 값은 인접합니다. 현재 원소가 왼쪽 원소와 같고 둘 다 현재 라운드의 선택 범위에 있다면 그 값은 이미 시도되었으므로 현재 원소를 건너뜁니다.

동시에 **각 배열 위치는 한 번만 선택할 수 있습니다.** `start`가 이 제약도 처리합니다. $x_i$를 선택한 뒤 다음 라운드는 인덱스 $i + 1$에서 시작합니다. 앞 문제에서 `i`부터 다시 시작한 것과 달리 한 칸 증가시키므로 방금 사용한 위치를 재사용할 수 없습니다.

왼쪽과 같은 값을 건너뛰는 조건은 두 원소가 같은 라운드의 형제 선택일 때만 적용됩니다. 부모 깊이에서 하나의 복사본을 선택한 뒤 더 깊은 단계에서 같은 값을 만난다면, 여러 복사본을 포함하는 조합을 만들기 위해 그 원소가 필요할 수 있습니다.

조건을 작성할 때에는 현재 인덱스가 `start`보다 큰지도 함께 확인합니다. 그래야 같은 깊이에서 앞의 동일 값만 건너뛰고, 부모가 선택한 복사본 다음에 오는 동일 값을 자식 깊이에서 사용할 수 있습니다. 이 경계를 빠뜨리면 입력에 실제로 여러 번 존재하는 값을 필요한 만큼 사용하는 해까지 삭제됩니다.

### 코드 구현

```python
# 잠긴 원문의 13개 언어 중복 원소 부분집합 합 공식 코드가 이 위치에 삽입됩니다.
```

정렬은 중복 값을 이웃하게 만들어 상수 시간 비교로 중복을 발견하게 하고, 목표 초과 시 반복문 전체를 끝낼 수 있게 합니다. 하나의 전처리가 두 가지 가지치기 규칙을 동시에 가능하게 합니다. 다만 정렬이 입력 배열의 원래 순서를 바꾸므로 호출자가 순서를 보존해야 한다면 사본을 정렬해야 합니다.

아래 그림은 배열 $[4, 4, 5]$와 목표 $9$의 백트래킹 과정이며 네 종류의 가지치기를 포함합니다. 같은 라운드의 동일 원소 건너뛰기, 위치 재사용 방지, 목표 초과 시 중단, 해 기록 시 중단을 코드 주석과 함께 추적해 보세요.

각 재귀 호출의 진입과 종료에서 경로와 남은 목표값이 서로 일치하는지 확인하면 구현을 검증하기 쉽습니다. 해를 기록한 뒤에는 양수만 존재하므로 더 선택할 필요가 없고 바로 돌아갈 수 있습니다. 실패한 가지에서도 마지막 선택을 제거한 뒤에만 다음 형제 후보를 시도해야 하며, 그렇지 않으면 서로 다른 조합의 원소가 한 경로에 섞입니다.

작은 예제로 재귀 트리를 직접 그리면 `start`의 두 역할을 구분하기 쉽습니다. 첫 문제에서는 같은 위치의 반복 선택을 허용하고, 둘째 문제에서는 다음 위치부터 시작해 재사용을 막습니다. 여기에 같은 깊이의 중복 건너뛰기까지 더해져도 각 규칙은 서로 다른 종류의 가지를 제거합니다.
