# 연습문제

## 개념 복습

### 이진 탐색은 구간을 어떻게 줄일까?

배열 `[1, 3, 5, 7, 9, 11, 13]`에서 `11`을 찾는 과정을 쓰세요.

??? success "정답"

    가운데 `7`보다 `11`이 크므로 왼쪽 절반을 버립니다. `[9,11,13]`의 가운데가 `11`이므로 두 번의 비교로 찾습니다. 매 단계에서 적어도 절반을 제외하므로 $O(\log n)$입니다.

### 중복 원소의 왼쪽과 오른쪽 경계

`[1, 2, 2, 2, 4]`에서 값 `2`의 첫 인덱스와 마지막 인덱스를 찾으세요.

??? success "정답"

    왼쪽 경계는 1, 오른쪽 경계는 3입니다. 왼쪽 경계는 `2`를 만나도 왼쪽을 계속 찾고, 오른쪽 경계는 오른쪽을 계속 찾습니다.

### 데이터에 맞는 검색 방법 선택

정렬되지 않은 작은 목록, 정렬된 큰 배열, 순서가 필요 없고 반복 검색하는 키 집합에 각각 선형 검색, 이진 탐색, 해시 테이블 중 무엇을 쓸지 설명하세요.

??? success "정답"

    작은 미정렬 목록은 준비 비용이 없는 선형 검색, 큰 정렬 배열은 이진 탐색, 반복 키 조회는 평균 $O(1)$인 해시 테이블이 적합합니다. 해시 테이블은 추가 메모리가 필요합니다.
