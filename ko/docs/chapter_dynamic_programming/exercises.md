# 연습문제

## 개념 복습

### 동적 계획법은 언제 적합한가?

한 학습자가 “점화식을 쓸 수 있으면 항상 동적 계획법을 써야 한다”고 말합니다.
다음 각 과제에 동적 계획법, 백트래킹, 단순 반복문이나 `dp` 테이블 없는 수학 공식을 사용해야 하는지 결정하고, 가장 중요한 이유 하나를 설명하세요.

방법을 고를 때에는 점화식의 존재만 확인하지 말고, 같은 하위 문제가 여러 선택 경로에서 반복되는지, 최적해 하나가 필요한지 아니면 모든 구체적 해를 출력해야 하는지, 이전 계산을 저장했을 때 실제로 중복 작업이 줄어드는지를 함께 살펴보세요. 상태의 의미와 전이의 방향을 말로 설명할 수 있어야 구현도 올바르게 검증할 수 있습니다.

작은 입력을 손으로 추적해 판단을 확인하세요.

<!-- numbered-subquestions -->

1. 액면가 `[1, 3, 4]`를 여러 번 사용하여 금액 6을 최소 동전 수로 만드세요.
2. `[1, 2, 3]`의 모든 순열을 나열하세요.
3. $1 + 2 + \dots + n$을 계산하세요.

    동적 계획법이 적합한 과제에는 `dp[i]`의 의미도 쓰세요.

??? success "정답"

    1. 동적 계획법이 적합합니다. `dp[i]`를 금액 `i`를 만드는 데 필요한 최소 동전 수라고 둡니다.
        `i`보다 크지 않은 각 동전 `c`에 대해 `dp[i-c] + 1`이 후보가 되고 그중 최솟값을 선택합니다.
        서로 다른 선택 경로가 같은 남은 금액을 반복해서 만나며 큰 금액의 최적해를 더 작은 금액의 최적해로 구성할 수 있습니다.
        금액 6의 답은 `3 + 3`을 사용하는 2개입니다.

    2. 백트래킹이 적합합니다. 문제는 6개의 순열을 모두 실제로 생성해야 합니다. 원소 하나를 선택하고 탐색을 이어 간 뒤 선택을 취소하고 다른 가지를 시도할 수 있습니다.
        어떤 방법을 쓰더라도 모든 순열을 출력하려면 각 순열을 열거해야 합니다.

    3. 반복문 하나나 등차수열의 합 공식이면 충분합니다. `S(i) = S(i-1) + i`라는 점화식을 쓸 수 있지만 `S(i)`는 더 작은 값 `S(i-1)` 하나에만 의존합니다.
        각 중간 합을 한 번씩만 계산하므로 겹치는 하위 문제가 없고 `dp` 테이블도 필요하지 않습니다. “점화식을 쓸 수 있다”와 “동적 계획법이 필요하다”는 같은 말이 아닙니다.

### 배낭 테이블의 한 칸 계산하기

무게 `wgt = [1, 2, 3]`, 가치 `val = [5, 11, 15]`, 용량 4인 0-1 배낭 문제를 생각해 봅시다.
`dp[i][c]`는 앞의 $i$개 물건만 사용하고 용량 한도가 $c$일 때 얻을 수 있는 최대 가치이며, 배낭을 정확히 가득 채울 필요는 없습니다.

`dp[2][4] = 16`, `dp[2][1] = 5`가 주어졌을 때 상태 `dp[3][4]`만 계산하세요.

<!-- numbered-subquestions -->

1. 세 번째 물건을 선택하지 않을 때 후보 가치는 얼마입니까?
2. 세 번째 물건을 선택하면 남은 용량과 후보 가치는 얼마입니까?
3. `dp[3][4]`는 얼마여야 하며 어떤 물건을 선택한 결과입니까?

??? success "정답"

    1. 세 번째 물건을 선택하지 않으면 앞의 두 물건으로 구한 결과를 유지하므로 후보는 `dp[2][4] = 16`입니다.

    2. 세 번째 물건의 무게는 3이므로 선택 뒤 남은 용량은 $4-3=1$입니다.
        후보 가치는 `dp[2][1] + 15 = 5 + 15 = 20`입니다.

    3. 16과 20을 비교하면 `dp[3][4] = 20`입니다. 첫 번째와 세 번째 물건을 선택한 결과이며
        총무게는 $1+3=4$, 총가치는 $5+15=20$입니다.

        이 계산은 0-1 배낭에서 한 번 수행하는 “선택 또는 비선택” 비교를 보여 줍니다.

### 배낭 용량은 어느 방향으로 갱신해야 하는가?

무게 2, 가치 5인 물건 하나와 용량 4인 0-1 배낭이 있습니다.
물건은 최대 한 번만 선택할 수 있고 일차원 배열의 초기값은 `dp = [0, 0, 0, 0, 0]`입니다.

한 학습자가 이 물건을 처리하면서 용량을 2부터 4까지 정방향으로 갱신했습니다.

- `dp[2]`를 갱신한 뒤 값은 5입니다.
- `dp[3]`을 갱신한 뒤 값도 5입니다.
- `dp[4]`를 갱신할 때 방금 얻은 `dp[2]`를 사용하여 `dp[4] = 10`을 만들었습니다.

<!-- numbered-subquestions -->

1. `dp[4] = 10`은 맞습니까? 그 이유는 무엇입니까?
2. 각 물건을 최대 한 번만 선택할 수 있으므로 `dp[4]`는 얼마여야 합니까?
3. 물건 하나를 처리할 때 용량을 큰 값에서 작은 값으로 갱신해야 합니까, 작은 값에서 큰 값으로 갱신해야 합니까? 이 순서는 어떤 문제를 막습니까?

??? success "정답"

    1. 틀린 결과입니다. 가치 10은 가치 5인 같은 물건을 두 번 넣었다는 뜻이므로 각 물건을 최대 한 번만 선택한다는 조건을 위반합니다.

    2. 이 물건은 하나뿐이므로 배낭에 최대 한 번만 담을 수 있고 `dp[4]`의 올바른 값은 5입니다.

    3. 용량을 4, 3, 2처럼 큰 값에서 작은 값 순으로 갱신해야 합니다.
        그러면 `dp[c]`를 계산할 때 읽는 `dp[c-2]`는 현재 물건을 처리하기 전의 값으로 남아 있어 같은 물건이 한 차례 안에서 다시 선택되지 않습니다.

### 계단 오르기 방법 수

`n`개의 계단이 있습니다. 한 번에 1칸 또는 2칸을 오르며 정확히 `n`번째 계단에서 멈춰야 합니다.
꼭대기에 도달하는 서로 다른 방법 수를 계산하세요. `n >= 1`이고, 1칸과 2칸 이동의 순서가 다르면 서로 다른 방법입니다.
일차원 동적 계획 배열을 사용하고, 아직은 두 상태만 남기는 공간 최적화를 적용하지 마세요.

??? tip "힌트"

    1. 계단 i에 도달하는 마지막 이동은 1칸 또는 2칸뿐입니다.
    2. 따라서 dp[i] = dp[i-1] + dp[i-2]입니다.
    3. n이 1 또는 2인 경우를 먼저 처리하고 계단 3부터 표를 채웁니다.

[LeetCode](https://leetcode.com/problems/climbing-stairs/)

### 0-1 배낭

길이가 같은 두 배열 `wgt`, `val`이 있습니다. 물건 `i`의 양의 정수 무게는 `wgt[i]`, 음이 아닌 정수 가치는 `val[i]`입니다.
용량 `cap`은 음이 아닌 정수이며 각 물건은 최대 한 번만 선택할 수 있습니다. 일차원 동적 계획법을 사용하여
`cap`을 넘지 않으면서 배낭에 담을 수 있는 가치의 최댓값을 구하세요.

??? tip "힌트"

    1. 길이가 cap + 1인 배열 dp를 만들고 dp[c]를 용량 한도 c에서의 최대 가치로 정의합니다.
    2. 물건 i를 처리할 때 선택하지 않는 dp[c]와 선택하는 dp[c-wgt[i]] + val[i]를 비교합니다.
    3. 같은 차례에 현재 물건을 다시 선택하지 않도록 용량을 큰 값에서 작은 값 순으로 갱신합니다.
