# 동적 계획법 입문

<u>동적 계획법</u>은 중요한 알고리즘 패러다임입니다. 큰 문제를 더 작은 하위 문제의 연속으로 분해하고, 이미 구한 해를 저장하여 같은 계산을 반복하지 않습니다. 이 방식은 실행 시간을 크게 줄일 수 있습니다.

이 절에서는 고전적인 예제로 출발합니다. 먼저 완전 탐색 백트래킹 해법을 만들고 탐색 트리에 겹치는 하위 문제가 나타나는 모습을 관찰한 뒤, 이를 더 효율적인 동적 계획법으로 단계적으로 바꿉니다.

!!! question "계단 오르기"

    $n$개의 계단이 있습니다. 한 번에 $1$칸 또는 $2$칸을 오를 수 있을 때, 꼭대기에 도달하는 서로 다른 방법은 몇 가지입니까?

아래 그림처럼 계단이 $3$개라면 꼭대기에 도달하는 방법은 모두 $3$가지입니다.

![세 번째 계단에 도달하는 방법 수](intro_to_dynamic_programming.assets/climbing_stairs_example.png)

목표는 경우의 수를 세는 것이므로 **백트래킹으로 모든 가능성을 열거할 수 있습니다**. 계단을 오르는 과정을 연속된 선택으로 생각합니다. 바닥에서 시작해 매번 $1$칸 또는 $2$칸을 선택하고, 정확히 꼭대기에 도달하면 계수를 $1$ 증가시키며, 꼭대기를 지나치면 그 가지를 잘라 냅니다. 공식 코드는 다음 위치에 삽입됩니다.

```python
# 잠긴 원문의 13개 언어 계단 오르기 백트래킹 공식 코드가 이 위치에 삽입됩니다.
```

## 방법 1: 완전 탐색

일반적인 백트래킹 코드는 문제 분해를 직접 드러내지 않습니다. 해결 과정을 일련의 의사 결정으로 보고, 선택을 시도하고 가지치기하면서 가능한 모든 해를 찾습니다.

이제 문제 분해의 관점에서 다시 살펴봅시다. $i$번째 계단에 도달하는 방법 수를 $dp[i]$라고 하겠습니다. $dp[i]$는 지금 풀려는 원문제이며, 그 하위 문제는 다음과 같습니다.

$$
dp[i-1], dp[i-2], \dots, dp[2], dp[1]
$$

한 번에 $1$칸 또는 $2$칸만 오를 수 있으므로 $i$번째 계단에 서기 직전에는 $i-1$번째 또는 $i-2$번째 계단에만 있을 수 있습니다. 즉, 현재 계단으로 들어오는 경로는 이 두 상태에서만 옵니다.

따라서 중요한 결론을 얻습니다. **$i-1$번째 계단에 도달하는 방법 수와 $i-2$번째 계단에 도달하는 방법 수를 더하면 $i$번째 계단에 도달하는 방법 수가 됩니다.** 점화식은 다음과 같습니다.

$$
dp[i] = dp[i-1] + dp[i-2]
$$

계단 오르기의 하위 문제 사이에는 이런 재귀 관계가 있으며, **원문제의 해를 하위 문제의 해로 구성할 수 있습니다**. 다음 그림은 이 상태 전이를 보여 줍니다.

![계단 오르기 방법 수의 재귀 관계](intro_to_dynamic_programming.assets/climbing_stairs_state_transfer.png)

점화식으로부터 완전 탐색 해법을 작성할 수 있습니다. $dp[n]$에서 시작하여 **큰 문제를 더 작은 두 문제의 합으로 재귀적으로 분해**하고, 가장 작은 문제인 $dp[1]$과 $dp[2]$에 도달할 때까지 계속합니다. 기저 문제의 해는 이미 알고 있습니다. $dp[1] = 1$, $dp[2] = 2$이며 각각 $1$번째와 $2$번째 계단에 도달하는 방법이 $1$가지와 $2$가지라는 뜻입니다.


## 방법 2: 메모이제이션

효율을 높이려면 **겹치는 하위 문제를 각각 한 번만 계산해야 합니다**. 배열 `mem`을 선언해 하위 문제의 해를 저장하고, 탐색 중 반복 계산을 잘라 냅니다.

1. $dp[i]$를 처음 계산하면 결과를 `mem[i]`에 기록합니다.
2. $dp[i]$가 다시 필요하면 더 분해하지 않고 `mem[i]`에서 바로 읽습니다.

## 방법 3: 동적 계획법

**메모이제이션은 “하향식” 방법입니다.** 루트의 원문제에서 시작해 더 작은 문제로 재귀적으로 분해하고, 이미 아는 기저 문제에 도달합니다. 그 뒤 재귀가 돌아오면서 아래 단계의 해를 모아 원문제의 해를 구성합니다.

반대로 **동적 계획법은 “상향식” 방법입니다.** 가장 작은 하위 문제의 해에서 출발해 더 큰 문제의 해를 반복적으로 만들고, 마지막에 원문제의 답을 얻습니다.

동적 계획법에는 재귀의 복귀 과정이 필요하지 않으므로 반복문만 사용합니다. 다음 코드에서 배열 `dp`는 하위 문제의 해를 저장하며 메모이제이션의 `mem`과 같은 역할을 합니다.

```python
# 잠긴 원문의 13개 언어 계단 오르기 동적 계획법 공식 코드가 이 위치에 삽입됩니다.
```

아래 그림은 코드의 실행 과정을 보여 줍니다.

![계단 오르기 동적 계획법 과정](intro_to_dynamic_programming.assets/climbing_stairs_dp.png)

백트래킹과 마찬가지로 동적 계획법은 “상태”로 풀이 과정의 한 단계를 표현합니다. 각 상태는 하나의 하위 문제와 그 문제의 해에 대응합니다. 계단 오르기에서는 현재 계단 번호를 나타내는 변수 $i$가 상태를 결정합니다.

상태 $i$를 계산할 때 바로 앞의 두 인덱스 $i-1$과 $i-2$가 필요하며, 이 둘은 현재 계단으로 전이할 수 있는 유일한 이전 위치입니다.

지금까지 나온 용어를 정리하면 다음과 같습니다.

- 배열 `dp`를 <u>DP 테이블</u>이라고 하며, $dp[i]$는 상태 $i$에 대응하는 하위 문제의 해입니다.
- 가장 작은 하위 문제인 $1$번째와 $2$번째 계단의 상태를 <u>초기 상태</u>라고 합니다.
- 점화식 $dp[i] = dp[i-1] + dp[i-2]$를 <u>상태 전이 방정식</u>이라고 합니다.

## 공간 최적화

**$dp[i]$는 $dp[i-1]$과 $dp[i-2]$에만 의존하므로 모든 하위 문제의 해를 배열 `dp`에 보관할 필요가 없습니다.** 두 변수만 반복문을 따라 앞으로 굴리면 됩니다.

```python
# 잠긴 원문의 13개 언어 공간 최적화 동적 계획법 공식 코드가 이 위치에 삽입됩니다.
```

배열 `dp`를 없애면 공간 복잡도는 $O(n)$에서 $O(1)$로 감소합니다.

많은 동적 계획법 문제에서 현재 상태는 앞의 유한한 몇 상태에만 의존합니다. 필요한 상태만 남겨 메모리를 줄이는 과정을 “차원 축소”라고 볼 수 있으며, **이 공간 최적화 기법을 “롤링 변수” 또는 “롤링 배열”이라고 합니다**.
