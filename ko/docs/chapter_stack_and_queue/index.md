# 스택과 큐

![스택과 큐](../assets/covers/chapter_stack_and_queue.jpg)

!!! abstract

    스택은 고양이들이 차곡차곡 포개져 있는 모습과 같고, 큐는 고양이들이 한 줄로 순서를 기다리는 모습과 같습니다.

    두 자료구조는 각각 후입선출(LIFO, 나중에 들어온 원소가 먼저 나감)과 선입선출(FIFO, 먼저 들어온 원소가 먼저 나감)이라는 논리적 순서를 표현합니다. 이 장에서는 배열과 연결 리스트로 두 구조를 구현하고, 양쪽 끝을 모두 사용할 수 있는 덱까지 살펴봅니다.
