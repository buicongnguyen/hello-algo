# 연습문제

## 개념 복습

### 스택과 큐에서 어떤 원소가 먼저 나갈까?

`A`, `B`, `C`를 차례로 스택과 큐에 넣었습니다. 꺼내는 순서를 쓰세요.

??? success "정답"

    스택은 후입선출이므로 `C, B, A`, 큐는 선입선출이므로 `A, B, C` 순서입니다.

### 뒤쪽 인덱스가 배열 끝을 지나면 어떻게 될까?

길이 5의 배열로 큐를 구현했습니다. 여러 번 넣고 빼서 앞에는 빈칸이 있지만 뒤쪽 인덱스는 배열 끝에 도달했습니다. 모든 원소를 옮겨야 합니까?

??? success "정답"

    그렇지 않습니다. 원형 큐는 나머지 연산으로 뒤쪽 인덱스를 배열 처음으로 되돌려 빈칸을 재사용합니다. 따라서 $O(n)$ 이동이 필요 없습니다.

### 덱의 양끝 연산

덱 `[B, C]`의 앞에 `A`, 뒤에 `D`를 넣고 앞과 뒤에서 하나씩 꺼내세요.

??? success "정답"

    두 원소를 넣으면 `[A, B, C, D]`입니다. 앞에서 `A`, 뒤에서 `D`를 꺼내고 `[B, C]`가 남습니다. 양끝 연산은 모두 $O(1)$로 구현할 수 있습니다.

### 괄호 문자열 검사

`()[]{}`로만 이루어진 문자열에서 괄호의 종류와 순서가 올바른지 판단하세요.

??? tip "힌트"

    여는 괄호를 스택에 넣습니다. 닫는 괄호를 만나면 스택 꼭대기가 대응하는 여는 괄호여야 하며, 마지막에는 스택이 비어 있어야 합니다.
