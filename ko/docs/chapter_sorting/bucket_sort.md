# 버킷 정렬

앞에서 본 정렬은 원소 사이의 상대 순서를 비교하므로 일반 비교 모델에서 $O(n \log n)$보다 빠를 수 없습니다. 비교하지 않는 정렬은 값의 범위나 분포를 이용하여 선형 시간에 도달할 수 있습니다.

<u>버킷 정렬</u>은 분할 정복을 적용한 대표적인 방법입니다. 순서가 정해진 여러 버킷을 만들고 각 버킷이 값의 한 구간을 담당하게 합니다. 데이터를 버킷에 분배하고, 각 버킷 내부를 독립적으로 정렬한 뒤, 버킷 순서대로 이어 붙입니다.

버킷 경계가 오름차순이고 각 원소가 정확한 구간에 배치되면 앞 버킷의 모든 값은 뒤 버킷의 값보다 작거나 같습니다. 따라서 버킷 사이를 다시 비교할 필요 없이 내부 결과만 연결할 수 있습니다.

## 알고리즘 특성

버킷 정렬은 매우 큰 데이터 집합에도 활용할 수 있습니다. 예를 들어 백만 개의 레코드를 메모리에 한 번에 넣지 못한다면 여러 파일이나 버킷으로 분할하고, 메모리에 들어오는 버킷 하나씩 정렬한 뒤 최종 결과를 합칠 수 있습니다.

- **균등 분포 조건에서 시간 복잡도 $O(n + k)$**: 각 버킷에 약 $\frac{n}{k}$개가 들어갑니다. 한 버킷 정렬이 $O(\frac{n}{k} \log\frac{n}{k})$이면 전체 버킷 정렬은 $O(n \log\frac{n}{k})$입니다. 버킷 수 $k$가 충분히 크면 이 비용은 $O(n)$에 가까워집니다. 합치는 단계는 모든 버킷과 원소를 순회하여 $O(n + k)$입니다. 최악에는 모든 원소가 한 버킷에 들어가고 내부 정렬이 $O(n^2)$이 될 수 있습니다.
- **공간 복잡도 $O(n + k)$, 비제자리 정렬**: $k$개 버킷과 그 안에 총 $n$개 원소를 추가로 저장합니다. 외부 정렬에서는 이 공간이 메모리 대신 파일이나 여러 저장 장치에 분산될 수 있습니다.
- **안정성은 내부 정렬과 병합 방식에 의존**: 각 버킷에서 안정 정렬을 쓰고 같은 값의 삽입 순서를 보존하며 버킷을 순서대로 연결하면 전체도 안정적입니다.

성능은 단순히 버킷 수를 늘린다고 항상 좋아지지 않습니다. 버킷이 너무 적으면 내부 정렬 비용이 커지고, 너무 많으면 빈 버킷 관리와 초기화 비용 `k`가 커집니다. 데이터 크기와 분포, 사용할 수 있는 메모리를 함께 고려해 선택해야 합니다.

## 균등하게 분배하는 방법

이론상 버킷 정렬은 $O(n)$을 달성할 수 있지만 결정적인 조건은 원소가 비교적 고르게 분산되어야 한다는 점입니다. 실제 데이터는 자주 치우칩니다. 상품 가격은 낮은 영역에 밀집하고 높은 영역에는 드문 경우가 많습니다. 값 범위를 같은 폭으로 나누면 몇 버킷은 과부하되고 많은 버킷이 거의 비게 됩니다.

거친 경계로 시작한 뒤 원소가 너무 많은 버킷을 다시 여러 버킷으로 나누어 크기가 비슷해질 때까지 반복할 수 있습니다. 이 과정은 분할 트리를 형성합니다. 목표는 잎 버킷의 부하를 균형 있게 만드는 것이며 각 단계의 분기 수는 데이터 특성에 맞춰 선택할 수 있습니다.

![원소가 많은 버킷을 재귀적으로 분할](bucket_sort.assets/scatter_in_buckets_recursively.png)

이런 적응형 분할은 입력을 한 번 표본 조사하여 대략적인 분포를 파악한 뒤 수행할 수 있습니다. 버킷 경계를 조정하는 비용이 생기지만, 한 버킷에 집중되어 내부 정렬이 병목이 되는 위험을 줄입니다. 병렬 처리에서는 버킷 크기 균형이 작업자 사이의 부하 균형과도 직접 연결됩니다.

데이터의 확률 분포를 알고 있다면 등간격 대신 **분위수**를 기준으로 경계를 정할 수 있습니다. 완전히 정확한 분포가 아니어도 합리적인 모델이면 균형이 크게 좋아집니다.

예를 들어 상품 가격이 정규 분포에 가깝다면 중심 영역의 구간을 꼬리보다 좁게 만들어 각 버킷이 비슷한 수의 원소를 받도록 할 수 있습니다.

![확률 분포에 따른 버킷 분할](bucket_sort.assets/scatter_in_buckets_distribution.png)

정리하면 버킷 정렬의 핵심은 내부 정렬 자체보다 값 공간을 어떻게 분할하느냐에 있습니다. 분포에 맞는 경계는 선형에 가까운 성능을 만들지만, 잘못된 경계는 알고리즘을 한 버킷의 내부 정렬로 퇴화시킵니다.
