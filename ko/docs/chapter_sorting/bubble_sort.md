# 버블 정렬

<u>버블 정렬</u>은 이웃한 두 원소를 계속 비교하고 필요한 경우 교환합니다. 큰 원소가 배열 끝으로 조금씩 이동하는 모습이 물속의 거품이 위로 떠오르는 것과 닮아 이런 이름이 붙었습니다.

왼쪽 끝에서 시작해 인접한 쌍을 차례로 비교합니다. 왼쪽 원소가 오른쪽 원소보다 크면 두 값을 교환합니다. 한 번 끝까지 지나가면 현재 구간의 최댓값이 가장 오른쪽에 놓입니다.

## 알고리즘 과정

길이가 $n$인 배열을 생각해 봅시다.

1. $n$개 원소에 한 번의 버블 연산을 수행하여 최댓값을 올바른 위치로 보냅니다.
2. 남은 $n - 1$개 원소에 다시 수행하여 두 번째로 큰 원소를 고정합니다.
3. 이 과정을 반복합니다. $n - 1$라운드가 끝나면 가장 큰 $n - 1$개 원소가 모두 고정됩니다.
4. 남은 한 원소는 반드시 최솟값이므로 배열 전체가 정렬됩니다.

![버블 정렬 전체 과정](bubble_sort.assets/bubble_sort_overview.png)

## 효율 최적화

한 라운드에서 교환이 한 번도 일어나지 않았다면 현재 배열은 이미 정렬되어 있으므로 즉시 종료할 수 있습니다. `flag`로 교환 발생 여부를 기록합니다.

이 최적화 뒤에도 평균과 최악 시간 복잡도는 $O(n^2)$입니다. 그러나 입력이 이미 정렬되어 있으면 한 번의 순회만 수행하므로 최선 시간 복잡도는 $O(n)$으로 줄어듭니다. 거의 정렬된 데이터에서도 교환 없는 라운드를 빨리 만나 불필요한 후속 순회를 피할 수 있습니다.

## 알고리즘 특성

- **시간 복잡도 $O(n^2)$, 적응형**: 각 라운드는 $n - 1$, $n - 2$, $\dots$, $2$, $1$개의 쌍을 순회하여 총 $(n - 1) n / 2$번 비교합니다. 조기 종료 덕분에 최선의 경우 $O(n)$입니다.
- **공간 복잡도 $O(1)$, 제자리 정렬**: 두 포인터 $i$와 $j$, 교환용 임시 변수와 플래그만 사용하므로 고정 공간입니다.
- **안정 정렬**: 같은 값을 가진 두 원소는 교환하지 않으므로 원래 상대적 순서가 유지됩니다. 안정성을 보존하려면 비교 조건을 “크거나 같음”이 아니라 반드시 “큼”으로 두어야 합니다.
