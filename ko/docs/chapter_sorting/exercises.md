# 연습문제

## 개념 복습

### 선택 정렬과 버블 정렬의 처음 두 라운드

배열 `[4, 2, 5, 1, 3]`을 다음 두 방법으로 오름차순 정렬합니다.

<!-- numbered-subquestions -->

1. 선택 정렬의 처음 두 라운드를 시뮬레이션하세요. 각 라운드 뒤 배열과 확정된 위치를 쓰세요.
2. 버블 정렬의 첫 라운드를 시뮬레이션하세요. 결과 배열, 교환 횟수, 확정된 위치를 쓰세요.

??? success "정답"

    1. 처음 두 라운드는 다음과 같습니다.

        | 라운드 | 배열 | 설명 |
        | --- | --- | --- |
        | 1 | `[1, 2, 5, 4, 3]` | 최솟값 1을 선택하여 첫 원소와 교환 |
        | 2 | `[1, 2, 5, 4, 3]` | 2가 이미 인덱스 1에 있으므로 교환하지 않음 |

        앞의 두 위치가 확정되었습니다. 이후에는 `[5, 4, 3]`에서 최솟값을 찾으면 됩니다.

    2. 인접한 쌍을 차례로 비교합니다. 4와 2를 교환하고, 4와 5는 그대로 두고, 5와 1을 교환한 뒤 5와 3을 교환합니다.
        세 번 교환한 결과는 `[2, 4, 1, 3, 5]`입니다. 최댓값 5가 끝에 도달했으므로 마지막 위치가 확정됩니다.

        선택 정렬은 왼쪽의 정렬된 접두사를 늘리고, 버블 정렬은 오른쪽의 정렬된 접미사를 늘린다는 차이가 있습니다.

### 같은 값의 상대 순서가 바뀔 수 있을까?

배열 $[2_a, 2_b, 1]$에서 $2_a$와 $2_b$는 같은 값을 가지며 아래첨자는 원래 순서를 표시합니다.

<!-- numbered-subquestions -->

1. 선택 정렬의 첫 라운드 뒤 배열을 쓰세요. $2_a$와 $2_b$의 상대 순서가 바뀌나요?
2. 버블 정렬의 첫 라운드 뒤 배열을 쓰세요. $2_a$와 $2_b$의 상대 순서가 바뀌나요?
3. 두 결과를 바탕으로 같은 원소의 원래 순서를 유지하는 측면에서 두 알고리즘의 차이를 설명하세요.

??? success "정답"

    1. 선택 정렬은 최솟값 1을 선택하여 첫 원소 $2_a$와 교환하고
        $[1, 2_b, 2_a]$를 만듭니다. $2_a$가 $2_b$ 뒤로 이동했으므로 상대 순서가 바뀌었습니다.

    2. 버블 정렬은 먼저 $2_a$와 $2_b$를 비교합니다. 두 값이 같으므로 교환하지 않습니다. 다음으로 $2_b$와 1을 비교하여 교환하면
        $[2_a, 1, 2_b]$가 됩니다. $2_a$가 계속 $2_b$ 앞에 있으므로 상대 순서가 유지됩니다.

    3. 선택 정렬은 한 원소를 멀리 떨어진 위치와 교환할 수 있어 불안정합니다. 버블 정렬은 왼쪽이 오른쪽보다 클 때만 인접한 쌍을 교환합니다. 같은 원소끼리는 교환하지 않으므로 안정적입니다.

        안정성은 값의 정렬 결과만 보고 판단할 수 없습니다. 같은 키를 가진 객체에 식별자를 붙여 정렬 전후의 상대 순서를 비교해야 합니다.

### 계수 정렬과 기수 정렬 비교

학교에서 정확히 8자리인 학생 번호를 매우 많이 정렬해야 합니다.

<!-- numbered-subquestions -->

1. 가장 낮은 자릿수부터 시작하면 기수 정렬은 몇 라운드가 필요한가요?
2. 번호 전체를 정수로 보고 계수 정렬을 사용하면 계수 배열의 많은 칸이 사용되지 않는 이유는 무엇인가요?
3. 고정 8자리 번호에는 계수 정렬과 기수 정렬 중 무엇이 더 적합한가요? 이유를 설명하세요.

??? success "정답"

    1. 번호가 8자리이므로 일의 자리부터 가장 높은 자리까지 8라운드가 필요합니다. 각 라운드는 0–9의 열 가지 값만 분류합니다.

    2. 직접 계수 정렬하면 가능한 모든 8자리 값마다 칸 하나가 필요합니다. 실제 학생에게 부여된 번호는 그중 매우 작은 일부뿐이므로 대부분의 계수는 항상 0입니다.

    3. 기수 정렬이 더 적합합니다. 길이가 고정되고 각 자릿수는 열 가지 값뿐이므로 작은 계수 배열을 사용하는 안정 분류를 8번 수행하면 됩니다. 전체 번호를 대상으로 하는 계수 정렬은 매우 희소한 값 범위에 큰 메모리를 낭비합니다.

        이 선택은 원소 수뿐 아니라 키 공간의 밀도와 자릿수 구조까지 살펴보아야 함을 보여 줍니다.

### 병합 정렬로 배열 정렬하기

정수 배열 `nums`가 주어집니다. 내장 정렬 함수를 호출하지 말고 병합 정렬을 직접 구현하여 원소를 비내림차순으로 정렬하고 결과를 반환하세요.

분할 단계와 병합 단계의 책임을 나누고, 각 재귀 호출이 반환될 때 담당 구간이 이미 정렬되어 있다는 불변식을 유지하세요.

??? tip "힌트"

    1. 길이가 1 이하인 구간은 이미 정렬되어 있습니다.
    2. 가운데에서 구간을 나누고 두 절반을 재귀적으로 정렬합니다.
    3. 두 포인터로 정렬된 두 절반을 임시 배열에 병합한 뒤 원래 배열에 다시 씁니다.

### 계수 정렬로 정수 배열 정렬하기

정수 배열 `nums`와 음이 아닌 정수 $K$가 주어집니다. 모든 원소는 $0$부터 $K$ 사이에 있습니다.

계수 정렬로 비내림차순 결과를 `nums`에 다시 쓰고 배열을 반환하세요. 비교 연산으로 순서를 결정하거나 내장 정렬 함수를 호출하면 안 됩니다.

값의 범위가 입력으로 주어졌으므로 계수 배열의 크기와 각 값의 결과 기록 횟수를 정확히 연결해야 합니다.

완료 뒤에는 배열이 비내림차순인지 작은 예제로 직접 확인하세요.

??? tip "힌트"

    1. 모든 원소가 알려진 범위에 있으므로 값을 계수 배열의 인덱스로 직접 사용합니다.
    2. `nums`를 한 번 순회하며 해당 위치의 계수를 증가시킵니다.
    3. 계수 배열을 작은 값부터 순회합니다. 값 `x`가 여러 번 나타나면 그 횟수만큼 `x`를 `nums`에 연속 기록합니다.
