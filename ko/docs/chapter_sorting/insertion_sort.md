# 삽입 정렬

<u>삽입 정렬</u>은 사람이 손에 든 카드를 정리하는 방식과 비슷하게 동작하는 단순한 알고리즘입니다.

각 라운드에서 정렬되지 않은 구간의 원소 하나를 기준값 `base`로 선택합니다. 왼쪽의 정렬된 구간과 뒤에서부터 비교하며, 기준값이 들어갈 위치를 찾은 뒤 그 자리에 삽입합니다.

아래 그림은 한 번의 삽입을 보여 줍니다. 목표 위치와 `base` 사이의 원소들을 한 칸씩 오른쪽으로 이동하고, 새로 생긴 빈칸에 `base` 값을 기록합니다. 원소를 매번 서로 교환하지 않고 이동시킨다는 점이 버블 정렬과 다릅니다.

![배열에 한 원소를 삽입하는 연산](insertion_sort.assets/insertion_operation.png)

## 알고리즘 과정

1. 처음에는 첫 번째 원소 하나를 정렬된 구간으로 봅니다.
2. 두 번째 원소를 `base`로 선택해 올바른 위치에 삽입하면 앞의 두 원소가 정렬됩니다.
3. 세 번째 원소를 `base`로 선택해 삽입하면 앞의 세 원소가 정렬됩니다.
4. 마지막 원소까지 같은 과정을 반복합니다. 마지막 라운드가 끝나면 배열 전체가 정렬됩니다.

길이가 $n$인 배열은 최대 $n - 1$번 삽입합니다. 매 라운드가 시작될 때 왼쪽 접두사는 이미 정렬되어 있고, 삽입 뒤에는 그 접두사의 길이가 하나 늘어납니다. 이 불변식이 알고리즘의 정확성을 설명합니다.

## 알고리즘 특성

- **시간 복잡도 $O(n^2)$, 적응형**: 최악의 경우 각 삽입은 $n - 1$, $n-2$, $\dots$, $2$, $1$번 이동하고 합은 $(n - 1) n / 2$이므로 $O(n^2)$입니다. 데이터가 이미 정렬되어 있으면 각 라운드가 즉시 멈추어 최선 시간은 $O(n)$입니다. 거의 정렬된 입력에서는 실제 이동 횟수가 역순 쌍의 수와 가까워집니다.
- **공간 복잡도 $O(1)$, 제자리 정렬**: 포인터 $i$, $j$와 기준값 하나만 저장하므로 고정 공간을 사용합니다.
- **안정 정렬**: 새 원소는 자신과 같은 원소들의 뒤에 놓입니다. 비교 조건이 같은 값까지 이동시키지 않으므로 같은 키의 상대적 순서가 보존됩니다.

## 삽입 정렬의 장점

삽입 정렬은 $O(n^2)$이고 뒤에서 배울 퀵 정렬은 평균 $O(n \log n)$입니다. 그런데도 **작은 데이터 집합에서는 삽입 정렬이 더 빠른 경우가 많습니다.**

퀵 정렬 같은 분할 정복 알고리즘은 구간 분할, 함수 호출, 재귀 스택 관리에 추가 비용을 냅니다. 데이터가 작으면 $n^2$과 $n \log n$의 차이가 아직 충분히 크지 않아 점근 복잡도보다 각 반복의 실제 연산 수가 더 큰 영향을 줍니다. 삽입 정렬의 내부 반복은 비교와 대입처럼 단순하고 메모리를 연속적으로 접근하여 캐시에도 유리합니다.

이 때문에 여러 표준 라이브러리는 혼합 전략을 씁니다. 큰 배열에는 분할 정복 알고리즘을 적용하다가 부분 배열이 충분히 짧아지면 삽입 정렬로 전환합니다. 이미 어느 정도 정렬된 입력에서도 적응성이 실제 성능을 개선합니다.

버블, 선택, 삽입 정렬은 모두 $O(n^2)$이지만 실무에서는 삽입 정렬이 더 자주 등장합니다.

- 버블 정렬은 교환에 의존하며 일반적으로 임시 변수 하나와 세 번의 대입이 필요합니다. 삽입 정렬은 주로 한 번의 대입으로 값을 이동하므로 상수 비용이 더 작습니다.
- 선택 정렬은 입력 순서와 무관하게 같은 수의 비교를 수행합니다. 삽입 정렬은 이미 정렬된 부분을 활용하므로 부분적으로 정렬된 데이터에서 뚜렷한 이점이 있습니다.
- 선택 정렬은 불안정하여 다단계 정렬에 부적합하지만, 삽입 정렬은 같은 키의 순서를 유지합니다.

따라서 작은 배열, 거의 정렬된 배열, 또는 안정성이 필요한 내부 단계에서 삽입 정렬은 단순한 교육용 방법을 넘어 실용적인 구성 요소가 됩니다.

온라인으로 값이 하나씩 도착하는 상황에도 잘 맞습니다. 기존 접두사가 이미 정렬되어 있다면 새 원소 하나만 적절한 위치에 삽입하면 되므로, 매번 전체 배열을 처음부터 다시 정렬할 필요가 없습니다. 다만 배열 중간 삽입은 뒤쪽 원소 이동을 요구하므로 데이터가 크고 역순 쌍이 많을 때는 다른 알고리즘이 더 적합합니다.
