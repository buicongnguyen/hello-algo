# 힙 정렬

!!! tip

    이 절을 읽기 전에 “힙” 장에서 힙 구조, 힙 만들기, 아래로 힙화 연산을 먼저 익히는 것이 좋습니다.

<u>힙 정렬</u>은 힙을 바탕으로 한 효율적인 알고리즘입니다. 직접적인 방법은 최소 힙을 만든 뒤 루트의 최솟값을 계속 꺼내 결과 배열에 기록하는 것입니다. 올바르지만 입력 크기만큼의 보조 배열이 필요합니다.

제자리 버전은 최대 힙을 사용합니다. 루트의 최댓값을 힙 구간 마지막 원소와 교환하면 입력 배열의 오른쪽부터 오름차순 결과가 완성됩니다. 교환된 최댓값은 힙 범위에서 제외되고 다시 움직이지 않습니다.

## 알고리즘 과정

길이가 $n$인 배열을 생각해 봅시다.

1. 배열에서 최대 힙을 만듭니다. 가장 큰 원소가 루트에 놓입니다.
2. 루트와 힙의 마지막 원소를 교환하고 힙 길이를 $1$ 줄이며 정렬된 원소 수를 $1$ 늘립니다.
3. 루트부터 아래로 힙화하여 최대 힙 성질을 복구합니다.
4. 2번과 3번을 반복합니다. $n - 1$라운드 뒤 배열 전체가 정렬됩니다.

매 라운드에는 왼쪽의 아직 정렬되지 않은 최대 힙과 오른쪽의 정렬된 접미사가 존재합니다. 힙의 모든 원소는 이미 고정된 접미사의 원소보다 작거나 같고, 루트는 남은 원소 중 가장 큽니다.

## 알고리즘 특성

- **시간 복잡도 $O(n \log n)$, 비적응형**: 힙 만들기는 $O(n)$이고, 최댓값을 꺼내 아래로 힙화하는 작업은 $O(\log n)$이며 총 $n - 1$번 반복합니다. 입력이 이미 정렬되어 있어도 같은 종류의 힙 연산을 수행합니다.
- **공간 복잡도 $O(1)$, 제자리 정렬**: 소수의 인덱스 변수만 $O(1)$ 메모리를 사용하며 교환과 힙화가 모두 원래 배열에서 일어납니다.
- **불안정 정렬**: 루트와 힙 마지막 원소의 장거리 교환이 같은 키를 가진 원소의 상대적 순서를 바꿀 수 있습니다.

힙 정렬은 퀵 정렬과 달리 입력 선택에 따라 시간이 제곱으로 악화되지 않고, 병합 정렬과 달리 큰 보조 배열도 필요하지 않습니다. 그래서 최악 시간 상한과 작은 보조 공간이 동시에 중요한 상황에 유용합니다. 다만 배열 안에서 부모와 자식 인덱스를 오가는 접근은 연속 순회보다 캐시 지역성이 낮아 실제 속도에서 퀵 정렬보다 불리할 수 있습니다.
