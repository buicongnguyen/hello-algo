# 연습문제

## 개념 복습

### 어떤 작업이 분할 정복에 적합한가?

한 학생이 아래 작업을 “두 절반으로 나누고, 각 절반을 따로 해결한 뒤 결과를 합치는” 방식으로 풀려고 합니다. 각 작업을 “분할 정복에 적합함”, “분할 정복을 쓸 수 있지만 총 작업량은 줄지 않음”, “두 절반을 독립적으로 풀 수 없음”으로 분류하고 이유를 설명하세요.

<!-- numbered-subquestions -->

1. 정렬되지 않은 배열을 정렬합니다.
2. 배열의 최댓값을 찾습니다.
3. `push(x)`와 `pop()` 스택 연산을 주어진 순서대로 수행하고 각 `pop()`이 반환한 원소를 출력합니다.

??? success "정답"

    1. 적합합니다. 배열을 절반으로 나누고 각 부분을 독립적으로 정렬한 뒤 $O(n)$에 병합할 수 있습니다. 이것이 병합 정렬의 구조입니다.
    2. 분할 정복을 사용할 수 있지만 총 작업량은 줄지 않습니다. 두 부분을 합쳐도 모든 $n$개 원소를 검사해야 하므로 직접 순회할 때와 같이 $O(n)$입니다. 트리 형태로 계산하면 병렬화에는 도움이 될 수 있지만 비교 횟수의 점근 차수는 바뀌지 않습니다.
    3. 두 절반은 독립적이지 않습니다. 두 번째 절반이 시작될 때 스택에 무엇이 들어 있는지는 첫 번째 절반의 연산 결과에 달려 있습니다. 앞부분의 최종 상태를 모르면 뒷부분의 `pop()` 결과를 결정할 수 없습니다.

    분류할 때는 단순히 입력을 둘로 자를 수 있는지만 보지 말고, 두 부분이 같은 문제 계약을 갖는지와 독립적으로 계산 가능한지를 확인해야 합니다. 마지막으로 부분 해를 합치는 비용까지 원래 작업량과 비교해야 합니다.

### 제곱 분할법은 어떻게 계산을 줄이는가?

아래 재귀 함수는 분할 정복으로 $x^n$을 계산합니다.

```python
def fast_pow(x, n):
    if n == 0:
        return 1
    half = fast_pow(x, n // 2)
    if n % 2 == 0:
        return half * half
    return half * half * x
```

`fast_pow(3, 5)`를 계산하며 다음 질문에 답하세요.

<!-- numbered-subquestions -->

1. 재귀 호출이 내려갈 때 인수 `n`은 어떤 값을 차례로 가집니까?
2. 가장 깊은 호출에서 시작해 각 단계는 어떤 값을 반환합니까?
3. `fast_pow(x, n // 2)`를 두 번 쓰지 않고 결과를 `half`에 저장해야 하는 이유는 무엇입니까?

??? success "정답"

    1. 인수는 `5 → 2 → 1 → 0`의 순서로 변합니다. 지수가 매 단계 절반이 되어 기본 경우에 도달합니다.

    2. `n = 0`이면 `1`을 반환합니다. `n = 1`이면 $1×1×3=3$, `n = 2`이면 $3×3=9$, `n = 5`이면 $9×9×3=243$을 반환합니다.

    3. 두 식은 완전히 같은 부분 문제를 계산합니다. 결과를 `half`에 저장하면 각 단계에서 재귀 호출을 한 번만 하므로 깊이가 약 $\log n$입니다. 같은 호출을 두 번 작성하면 동일한 하위 계산을 반복하여 분할 정복으로 얻은 이점을 잃습니다.

    핵심은 지수를 절반으로 줄이는 것뿐 아니라 그 절반 문제의 해를 한 번만 계산해 재사용하는 것입니다. 재귀 트리의 각 단계에서 같은 자식이 두 번 생기지 않으므로 호출 경로가 한 줄로 유지됩니다.

### 순회 결과를 왼쪽·오른쪽 부분 트리로 나누기

중복 노드가 없는 이진 트리의 순회 결과가 다음과 같습니다.

- 전위 순회: `[A, B, D, E, C]`
- 중위 순회: `[D, B, E, A, C]`

루트에서 한 번만 두 부분으로 나누세요. 재귀를 계속하거나 전체 트리를 그릴 필요는 없습니다.

<!-- numbered-subquestions -->

1. 루트는 어느 노드입니까?
2. 중위 순회에서 왼쪽과 오른쪽 부분 트리에 해당하는 부분 수열은 무엇입니까?
3. 전위 순회에서 두 부분 트리에 해당하는 부분 수열은 무엇이며, 루트의 두 직접 자식은 어느 노드입니까?

??? success "정답"

    1. 전위 순회의 첫 노드가 루트이므로 루트는 `A`입니다.

    2. `A`는 중위 순회를 왼쪽 `[D, B, E]`와 오른쪽 `[C]`로 나눕니다.

    3. 왼쪽 부분 트리에는 노드가 3개 있으므로 전위 순회에서 `A` 다음의 세 원소 `[B, D, E]`가 왼쪽에 속합니다. 남은 `[C]`는 오른쪽입니다. 따라서 루트의 왼쪽 자식은 `B`, 오른쪽 자식은 `C`입니다.

### 제곱 분할법

실수 `x`와 정수 `n`이 주어졌을 때 언어의 내장 거듭제곱 함수를 사용하지 않고 $x^n$을 계산하세요. 매 단계 지수를 절반으로 줄이고 이미 계산한 부분 문제의 결과를 재사용하는 재귀 분할 정복을 사용합니다.

이 문제에서는 `x = 0`인 경우를 포함해 $x^0=1$로 정의합니다. `n < 0`일 때는 `x != 0`이 보장되며 답을 $(1/x)^{-n}$으로 바꿀 수 있습니다.

??? tip "힌트"

    1. `n`이 0이면 답은 1입니다.
    2. `x`의 `n // 2`제곱을 계산한 뒤 같은 재귀 호출을 다시 하지 말고 결과를 `half`에 저장하세요.
    3. `n < 0`이면 먼저 `x`를 `1 / x`로, `n`을 `-n`으로 바꿉니다. C++이나 Java에서는 가장 작은 32비트 정수를 음수로 바꿀 때 오버플로가 나지 않도록 먼저 64비트 정수로 변환하세요.
