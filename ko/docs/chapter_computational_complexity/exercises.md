# 연습문제

## 개념 복습

### 반복과 재귀의 시간·공간 복잡도

다음 두 함수는 모두 $n \ge 1$일 때 $1 + 2 + \dots + n$을 계산합니다. `n = 4`로 두고 실제 실행 순서를 따라간 뒤 효율을 비교하세요.

```python
def sum_iter(n):
    s = 0
    for i in range(1, n + 1):
        s += i
    return s

def sum_recur(n):
    if n == 1:
        return 1
    return n + sum_recur(n - 1)
```

1. `sum_iter(4)`의 각 반복 뒤 `s`는 얼마입니까?
2. `sum_recur(4)`의 호출 순서와 반환 과정은 어떻습니까?
3. 두 방법의 시간 및 공간 복잡도를 설명하세요.

??? success "정답"

    1. `i`는 `1, 2, 3, 4`, `s`는 `1, 3, 6, 10`이 됩니다.
    2. `sum_recur(4) → sum_recur(3) → sum_recur(2) → sum_recur(1)` 순서로 호출하고, 반환하며 `1`, `2 + 1 = 3`, `3 + 3 = 6`, `4 + 6 = 10`을 얻습니다.
    3. 둘 다 $O(n)$ 시간이 걸립니다. 반복문은 고정된 변수만 사용하므로 $O(1)$ 공간, 재귀는 최대 $n$개의 호출 프레임을 유지하므로 $O(n)$ 공간을 사용합니다.

### 세 코드 조각의 시간 복잡도

다음 코드를 시간 복잡도가 낮은 순서대로 배열하세요.

```python
# 조각 1
s = 0
for i in range(n):
    s += i

# 조각 2
s = 0
for i in range(n):
    for j in range(i, n):
        s += j

# 조각 3
while n > 1:
    n = n // 2
```

??? success "정답"

    조각 3은 $O(\log n)$, 조각 1은 $O(n)$, 조각 2는 $O(n^2)$입니다. 조각 3은 매번 `n`을 절반으로 줄이고, 조각 2는 총 $n+(n-1)+\dots+1=n(n+1)/2$번 실행합니다.

### 어느 뒤집기 방법이 공간을 덜 사용할까?

같은 길이의 새 배열에 역순으로 복사하는 방법과, 양끝의 두 인덱스를 안쪽으로 옮기며 제자리에서 교환하는 방법을 비교하세요.

??? success "정답"

    새 배열은 $O(n)$ 공간이 필요합니다. 두 인덱스 방법은 $O(1)$ 공간만 사용하며 제자리 연산이지만 입력 배열을 변경합니다.
