# 연습문제

## 개념 복습

### 반복과 재귀의 시간·공간 복잡도

아래 두 함수는 모두 $1 + 2 + \dots + n$을 계산합니다($n \ge 1$). `n`을 4로 두고 실제 실행 순서를 따라 질문에 답한 뒤 두 방법의 효율을 비교하세요.

```python
def sum_iter(n):
    s = 0
    for i in range(1, n + 1):
        s += i
    return s

def sum_recur(n):
    if n == 1:
        return 1
    return n + sum_recur(n - 1)
```

<!-- numbered-subquestions -->

1. `sum_iter(4)`를 실행할 때 각 반복이 끝난 뒤 `s`의 값은 무엇인가요?
2. `sum_recur(4)`에서는 어떤 함수 호출이 차례로 발생하나요? 가장 깊은 호출부터 반환될 때 결과는 어떻게 만들어지나요?
3. 두 방법의 시간 복잡도와 공간 복잡도는 무엇인가요? 앞의 실행 과정을 근거로 설명하세요.

??? success "정답"

    1. 반복 변수는 `1, 2, 3, 4`가 되고 `s`는 차례로 `1, 3, 6, 10`이 됩니다. 따라서 결과는 10입니다.

    2. 호출 순서는 `sum_recur(4) → sum_recur(3) → sum_recur(2) → sum_recur(1)`입니다. 마지막 호출이 1을 반환한 뒤 `2 + 1 = 3`, `3 + 3 = 6`, `4 + 6 = 10` 순서로 결과가 완성됩니다. 가장 깊은 지점에서는 네 호출이 아직 모두 반환되지 않았습니다.

    3. 두 함수 모두 입력에 비례하는 횟수만큼 반복하거나 호출하므로 시간 복잡도는 $O(n)$입니다. 반복 버전은 고정된 수의 변수만 사용하여 공간 복잡도가 $O(1)$입니다. 재귀 버전은 최대 $n$개의 호출이 동시에 스택에 남으므로 공간 복잡도가 $O(n)$입니다.

        공간 복잡도를 분석할 때는 코드에 보이는 변수뿐 아니라 재귀 호출이 차지하는 스택 프레임도 포함해야 합니다. 두 방법은 결과와 시간 성장 추세가 같지만 메모리 최고점은 다르며, 입력 제한이 크다면 재귀 깊이 제한도 함께 검토해야 합니다.

### 세 코드 조각의 시간 복잡도

다음 코드 조각은 모두 양의 정수 $n$을 입력받습니다. 시간 복잡도가 낮은 것부터 높은 것까지 정렬하고 각각의 복잡도를 쓰세요.

```python
# Fragment 1
s = 0
for i in range(n):
    s += i

# Fragment 2
s = 0
for i in range(n):
    for j in range(i, n):
        s += j

# Fragment 3
while n > 1:
    n = n // 2
```

??? success "정답"

    낮은 순서는 조각 3의 $O(\log n)$, 조각 1의 $O(n)$, 조각 2의 $O(n^2)$입니다.

    조각 3은 매번 $n$을 절반으로 줄이므로 약 $\log_2 n$회 실행합니다. 조각 1은 정확히 $n$회 반복합니다. 조각 2의 안쪽 루프는 $n,n-1,\dots,1$회 실행되어 총 $n(n+1)/2$번이므로 이차 복잡도입니다.

### 어느 뒤집기가 공간을 덜 사용하는가?

배열 `nums`의 모든 원소를 뒤집는 두 방법이 있습니다.

<!-- numbered-subquestions -->

1. 같은 길이의 새 배열 `res`를 만들고 원소를 역순으로 복사하여 반환합니다.
2. 인덱스 `i`, `j`를 양끝에서 안쪽으로 이동시키며 매 단계에서 `nums[i]`와 `nums[j]`를 교환합니다.

각 방법의 공간 복잡도는 무엇이며, 어느 방법이 제자리 연산인가요?

??? success "정답"

    1. 입력과 같은 길이의 보조 배열이 필요하므로 공간 복잡도는 $O(n)$입니다.

    2. 두 인덱스 변수만 사용하므로 공간 복잡도는 $O(1)$이며 제자리 연산입니다.

        제자리 뒤집기는 입력 배열 자체를 변경합니다. 원본을 유지해야 한다면 첫 번째 방법의 복사 비용을 피할 수 없습니다.

### 피보나치 수

피보나치 수열은 $F(0)=0$, $F(1)=1$이고 $n\ge2$일 때 $F(n)=F(n-1)+F(n-2)$로 정의됩니다.

음이 아닌 정수 $n$이 주어졌을 때 루프를 사용해 $F(n)$을 계산하여 반환하세요. 재귀는 사용하지 마세요.

해법은 입력이 커져도 직전 두 항만 유지해야 합니다. 반환값의 정확성뿐 아니라 반복 횟수와 동시에 저장되는 값의 수를 근거로 시간·공간 복잡도도 설명해 보세요.

작은 입력 몇 개를 손으로 추적하여 두 상태 변수가 어떤 순서로 바뀌는지도 확인하세요.

??? tip "힌트"

    1. `n`이 0 또는 1인 경우를 따로 처리합니다.
    2. 다음 항을 계산할 때는 직전 두 항만 필요하므로 전체 수열을 저장할 필요가 없습니다.
    3. 두 변수를 갱신할 때 이전 값이 사용되기 전에 덮어쓰지 않도록 주의합니다.
